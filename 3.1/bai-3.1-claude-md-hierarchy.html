Cách đo: mỗi file chứa một mã CANARY riêng (vd CANARY-PROJECT-7Q); Claude chỉ in được mã của file mà nó đã nạp. Cuối cùng tái hiện bẫy hay ra đề: người mới vào team không nhận được quy ước vì quy ước nằm trong ~/.claude/CLAUDE.md của người cũ.

5. Không có "file nào thắng"

CLAUDE.md: nối, không ghi đè

  • Mọi file tìm thấy được nối vào context, thứ tự rộng → hẹp (user → project → thư mục cha → cwd; CLAUDE.local.md sau CLAUDE.md cùng cấp).
  • Thứ tự nạp không phải độ ưu tiên. Hai quy tắc mâu thuẫn thì Claude có thể theo bất kỳ cái nào.
  • CLAUDE.md được gửi như tin nhắn user, không phải system prompt: là hướng dẫn, không đảm bảo tuân thủ.

Quy tắc bắt buộc → settings.json hoặc hook

  • settings.json CÓ thứ tự ưu tiên: managed > local > project > user, client ép thực thi.
  • Hook PreToolUse chặn được hành động bất kể Claude quyết định gì (bài 1.5).
  • lint_config.ts cảnh báo dòng kiểu NEVER, tuyệt đối không trong CLAUDE.md để gợi ý chuyển sang đây.

// Bài 3.1 – mô hình TĨNH: đứng ở thư mục X thì Claude Code nạp những file hướng dẫn nào, theo thứ tự nào.
// Không gọi model. Dựa trên tài liệu code.claude.com/docs/en/memory (đọc ngày 15/10/2026):
//   - Thứ tự: managed → user (~/.claude/CLAUDE.md) → project → local. "All discovered files are concatenated
//     into context rather than overriding each other": nạp sau KHÔNG có nghĩa là thắng.
//   - Lúc khởi động: CLAUDE.md và CLAUDE.local.md ở cwd và MỌI thư mục phía trên, từ gốc xuống cwd.
//     CLAUDE.local.md đứng sau CLAUDE.md cùng cấp.
//   - Thư mục CON của cwd: nạp ON-DEMAND, khi Claude đọc/ghi/sửa một file trong thư mục đó.
//   - `@path` import: nạp NGAY (eager), đường dẫn tương đối tính từ file chứa dòng import, tối đa 4 bước lồng.
//   - .claude/rules/*.md không có frontmatter `paths`: nạp lúc khởi động như .claude/CLAUDE.md.

// không. Tài liệu chỉ nói "CLAUDE.md và CLAUDE.local.md ở mọi thư mục phía trên"; mô hình này giả định có.
import { existsSync, readFileSync, readdirSync, statSync } from "node:fs";
import { homedir } from "node:os";
import { dirname, join, relative, resolve, sep } from "node:path";

export const CANARY_RE = /CANARY-[A-Z0-9]+(?:-[A-Z0-9]+)*/g;
export const USER_CANARY = "CANARY-USER-3H";
export const MAX_IMPORT_DEPTH = 4;

export interface Loaded {
  file: string; // đường dẫn tuyệt đối
  label: string; // hiển thị: tương đối với repo, hoặc ~/… cho user-level
  kind: "user" | "project" | "local" | "rule" | "import" | "directory";
  when: "launch" | "on-demand";
  canary?: string;
}

export interface LoadOptions {
  repoRoot: string;
  cwd: string; // tuyệt đối, nằm trong repoRoot
  userLevel: boolean; // phiên có nạp ~/.claude/CLAUDE.md (người mới clone: false)
  userClaudeMd?: string; // mặc định ~/.claude/CLAUDE.md
  readFiles?: string[]; // file Claude đọc trong phiên (tuyệt đối) → kích hoạt CLAUDE.md on-demand
}

export function canaryOf(file: string): string | undefined {
  const m = readFileSync(file, "utf8").match(CANARY_RE);
  return m?.[0];
}

/** Các dòng `@path` ngoài code span/code block, theo đúng thứ tự. */
export function importsOf(file: string): { raw: string; line: number }[] {
  const out: { raw: string; line: number }[] = [];
  let fenced = false;
  readFileSync(file, "utf8").split("\n").forEach((text, i) => {
    if (/^\s*```/.test(text)) fenced = !fenced;
    if (fenced) return;
    const noSpans = text.replace(/`[^`]*`/g, "");
    for (const m of noSpans.matchAll(/(?:^|\s)@((?:[^\s\\]|\\ )+)/g)) {
      if (m[1] === "import") continue; // từ khoá "@import" không tồn tại; lint_config.ts báo lỗi riêng
      out.push({ raw: m[1].replace(/\\ /g, " "), line: i + 1 });
    }
  });
  return out;
}

const isFile = (p: string) => existsSync(p) && statSync(p).isFile();

function rulesOf(dir: string): string[] {
  const root = join(dir, ".claude", "rules");
  if (!existsSync(root)) return [];
  const walk = (d: string): string[] =>
    readdirSync(d, { withFileTypes: true })
      .sort((a, b) => a.name.localeCompare(b.name))
      .flatMap((e) => (e.isDirectory() ? walk(join(d, e.name)) : e.name.endsWith(".md") ? [join(d, e.name)] : []));
  // Rule có frontmatter `paths:` chỉ nạp khi khớp file (bài 3.3), mô hình này chỉ lấy rule không có `paths`.
  return walk(root).filter((f) => !/^---\n[\s\S]*?\bpaths\s*:[\s\S]*?\n---/.test(readFileSync(f, "utf8")));
}

export function expectedLoading(o: LoadOptions): Loaded[] {
  const repoRoot = resolve(o.repoRoot);
  const cwd = resolve(o.cwd);
  const label = (f: string) => (f.startsWith(homedir() + sep) && !f.startsWith(repoRoot) ? "~/" + relative(homedir(), f) : relative(repoRoot, f));
  const out: Loaded[] = [];
  const seen = new Set<string>();

  const add = (file: string, kind: Loaded["kind"], when: Loaded["when"], depth = 0) => {
    if (seen.has(file) || !isFile(file)) return;
    seen.add(file);
    out.push({ file, label: label(file), kind, when, canary: canaryOf(file) });
    if (depth >= MAX_IMPORT_DEPTH) return;
    for (const imp of importsOf(file)) {
      const target = resolve(dirname(file), imp.raw); // tương đối với FILE chứa import, không phải cwd
      add(target, "import", when, depth + 1);
    }
  };

  if (o.userLevel) add(o.userClaudeMd ?? join(homedir(), ".claude", "CLAUDE.md"), "user", "launch");

  // Từ repoRoot xuống cwd (mô hình giới hạn trong repo; thư mục ngoài repo bỏ qua).
  const chain: string[] = [];
  for (let d = cwd; ; d = dirname(d)) {
    chain.unshift(d);
    if (d === repoRoot || d === dirname(d)) break;
  }
  for (const d of chain) {
    add(join(d, "CLAUDE.md"), d === repoRoot ? "project" : "directory", "launch");
    add(join(d, ".claude", "CLAUDE.md"), d === repoRoot ? "project" : "directory", "launch");
    for (const r of rulesOf(d)) add(r, "rule", "launch");
    add(join(d, "CLAUDE.local.md"), "local", "launch");
  }

  // On-demand: CLAUDE.md trong thư mục con của cwd, nạp khi Claude chạm vào file trong đó.
  for (const f of o.readFiles ?? []) {
    const abs = resolve(cwd, f);
    if (!abs.startsWith(cwd + sep)) continue;
    const dirs: string[] = [];
    for (let d = dirname(abs); d !== cwd && d.startsWith(cwd + sep); d = dirname(d)) dirs.unshift(d);
    for (const d of dirs) {
      add(join(d, "CLAUDE.md"), "directory", "on-demand");
      add(join(d, "CLAUDE.local.md"), "local", "on-demand");
    }
  }
  return out;
}

if (import.meta.url === `file://${process.argv[1]}`) {

  const fakeUser = join(import.meta.dirname, "test", "fixtures", "user_claude.md"); // file user-level MÔ PHỎNG

    [".", []],
    ["packages/api", []],

    [".", ["packages/api/src/routes.ts"]],
  ];

    for (const [cwd, reads] of cases) {

    }
  }
}

//   WARN : file > 200 dòng (tài liệu: tốn context, giảm mức tuân thủ)
//          import lồng quá 4 bước
//          quy tắc "cứng" (NEVER, MUST NOT, tuyệt đối không, cấm…): CLAUDE.md chỉ là hướng dẫn, quy tắc
//          bắt buộc nên chuyển sang settings.json (permissions.deny) hoặc hook PreToolUse
//          có CLAUDE.local.md.example nhưng .gitignore chưa có CLAUDE.local.md
import { existsSync, readFileSync, readdirSync } from "node:fs";
import { dirname, join, relative, resolve } from "node:path";
import { importsOf, MAX_IMPORT_DEPTH } from "./expected_loading.ts";

export interface Finding {
  level: "ERROR" | "WARN";
  file: string;
  line?: number;
  msg: string;
}

const MAX_LINES = 200;
const HARD_RULE = /\b(NEVER|MUST NOT|MUST|ALWAYS)\b|tuyệt đối không|không bao giờ|\bcấm\b/i;

/** Mọi file hướng dẫn trong repo (bỏ node_modules, .git). */
export function memoryFiles(repo: string): string[] {
  const out: string[] = [];
  const walk = (d: string) => {
    for (const e of readdirSync(d, { withFileTypes: true })) {
      if (e.name === "node_modules" || e.name === ".git") continue;
      const p = join(d, e.name);
      if (e.isDirectory()) walk(p);
      else if (/^CLAUDE(\.local)?\.md$/.test(e.name) || (p.includes(join(".claude", "rules")) && e.name.endsWith(".md"))) out.push(p);
    }
  };
  walk(repo);
  return out.sort();
}

function gitignored(repo: string, name: string): boolean {
  const gi = join(repo, ".gitignore");
  return existsSync(gi) && readFileSync(gi, "utf8").split("\n").some((l) => l.trim() === name || l.trim() === `/${name}` || l.trim() === `**/${name}`);
}

export function lintRepo(repo: string): Finding[] {
  const root = resolve(repo);
  const rel = (f: string) => relative(root, f);
  const out: Finding[] = [];

  const depthOf = (file: string, seen = new Set<string>()): number => {
    if (seen.has(file) || !existsSync(file)) return 0;
    seen.add(file);
    return Math.max(0, ...importsOf(file).map((i) => 1 + depthOf(resolve(dirname(file), i.raw), seen)));
  };

  for (const f of memoryFiles(root)) {
    const lines = readFileSync(f, "utf8").split("\n");
    lines.forEach((text, i) => {
      if (/^\s*@import\b/.test(text))
        out.push({ level: "ERROR", file: rel(f), line: i + 1, msg: 'dùng "@import": không có từ khoá này, viết "@đường/dẫn/file.md"' });
      if (HARD_RULE.test(text))
        out.push({ level: "WARN", file: rel(f), line: i + 1, msg: "quy tắc bắt buộc: CLAUDE.md không đảm bảo tuân thủ, nên chặn bằng settings.json (permissions.deny) hoặc hook PreToolUse" });
    });
    for (const imp of importsOf(f)) {
      const target = resolve(dirname(f), imp.raw);
      if (!existsSync(target))
        out.push({ level: "ERROR", file: rel(f), line: imp.line, msg: `import @${imp.raw} không tồn tại (tính từ ${rel(dirname(f)) || "."}/ → ${rel(target)})` });
    }
    if (lines.length > MAX_LINES) out.push({ level: "WARN", file: rel(f), msg: `${lines.length} dòng (> ${MAX_LINES}): tách bằng .claude/rules/ có paths (bài 3.3) để giảm context` });
    const depth = depthOf(f);
    if (depth > MAX_IMPORT_DEPTH) out.push({ level: "WARN", file: rel(f), msg: `import lồng ${depth} bước (tối đa ${MAX_IMPORT_DEPTH})` });
  }

  if (existsSync(join(root, "CLAUDE.local.md")) && !gitignored(root, "CLAUDE.local.md"))
    out.push({ level: "ERROR", file: "CLAUDE.local.md", msg: ".gitignore chưa bỏ qua CLAUDE.local.md: ghi chú cá nhân sẽ bị commit" });
  else if (existsSync(join(root, "CLAUDE.local.md.example")) && !gitignored(root, "CLAUDE.local.md"))
    out.push({ level: "WARN", file: ".gitignore", msg: "nên thêm CLAUDE.local.md vào .gitignore" });
  return out.sort((a, b) => a.file.localeCompare(b.file) || (a.line ?? 0) - (b.line ?? 0));
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const repo = process.argv[2] ?? join(import.meta.dirname, "demo-repo");
  const found = lintRepo(repo);
  console.log(`Lint ${repo}: ${memoryFiles(repo).length} file hướng dẫn`);
  for (const f of found) console.log(`  ${f.level.padEnd(5)} ${f.file}${f.line ? `:${f.line}` : ""}  ${f.msg}`);
  const errors = found.filter((f) => f.level === "ERROR").length;
  console.log(`${errors} lỗi, ${found.length - errors} cảnh báo`);
  process.exitCode = errors ? 1 : 0;
}

// Bài 3.1 – so CANARY mà Claude in ra (stream-json của run_cli.sh) với mô hình expected_loading.ts.
// Dùng: node --experimental-strip-types report_cli.ts <results_cli> <.tmp> [user CLAUDE.md]
import { existsSync, readFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";
import { readStream, resultEvent, toolUses } from "../lib/cli_stream.ts";
import { CANARY_RE, expectedLoading, USER_CANARY } from "./expected_loading.ts";

export interface Row {
  who: string;
  name: string;
  cwd: string;
  expected: string[];
  seen: string[];
  missing: string[]; // mong đợi mà không thấy
  extra: string[]; // thấy mà không mong đợi
  reads: string[];
  ok: boolean;
  costUsd?: number;
}

const CASES = [
  { who: "me", name: "root", cwd: ".", reads: [] as string[] },
  { who: "me", name: "api", cwd: "packages/api", reads: [] },
  { who: "me", name: "web", cwd: "packages/web", reads: [] },
  { who: "newcomer", name: "root", cwd: ".", reads: [] },
  { who: "newcomer", name: "api", cwd: "packages/api", reads: [] },
  { who: "newcomer", name: "web", cwd: "packages/web", reads: [] },
  { who: "newcomer", name: "root-ondemand", cwd: ".", reads: ["packages/api/src/routes.ts"] },
];

export function compare(resultsDir: string, tmpDir: string, userClaudeMd = join(homedir(), ".claude", "CLAUDE.md")): Row[] {
  // Khối demo có trong user-level thật không (chỉ đọc, không sửa).
  const userHasCanary = existsSync(userClaudeMd) && readFileSync(userClaudeMd, "utf8").includes(USER_CANARY);
  const rows: Row[] = [];
  for (const c of CASES) {
    const file = join(resultsDir, c.who, `${c.name}.jsonl`);
    if (!existsSync(file)) continue;
    const repo = join(tmpDir, c.who);
    const expected = expectedLoading({
      repoRoot: repo,
      cwd: join(repo, c.cwd),
      userLevel: c.who === "me",
      userClaudeMd,
      readFiles: c.reads.map((r) => join(repo, r)),
    })
      .map((l) => l.canary)
      .filter((x): x is string => !!x && (x !== USER_CANARY || userHasCanary));
    const events = readStream(file);
    const text =
      (resultEvent(events)?.result as string | undefined) ??
      events
        .filter((e) => e.type === "assistant" && Array.isArray(e.message?.content))
        .flatMap((e) => e.message!.content.filter((b: any) => b.type === "text").map((b: any) => b.text))
        .join("\n");
    const seen = [...new Set(text.match(CANARY_RE) ?? [])].sort();
    const missing = expected.filter((x) => !seen.includes(x));
    const extra = seen.filter((x) => !expected.includes(x));
    const reads = toolUses(events)
      .filter((t) => t.name === "Read")
      .map((t) => String(t.input?.file_path ?? ""));
    rows.push({ ...c, expected, seen, missing, extra, reads, ok: !missing.length && !extra.length, costUsd: resultEvent(events)?.total_cost_usd });
  }
  return rows;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const [resultsDir, tmpDir, user] = process.argv.slice(2);
  const rows = compare(resultsDir, tmpDir, user || undefined);
  if (!rows.length) {
    console.log(`Không có kết quả trong ${resultsDir}: chạy ./run_cli.sh run trước`);
    process.exit(1);
  }
  let cost = 0;
  for (const r of rows) {
    cost += r.costUsd ?? 0;
    console.log(`\n${r.ok ? "OK  " : "KHÁC"} ${r.who.padEnd(8)} cwd=${r.cwd}${r.reads.length ? `  (đã Read: ${r.reads.map((p) => p.split("/").slice(-3).join("/")).join(", ")})` : ""}`);
    console.log(`     mong đợi: ${r.expected.join(", ") || "(không)"}`);
    console.log(`     thấy    : ${r.seen.join(", ") || "(không)"}`);
    if (r.missing.length) console.log(`     THIẾU   : ${r.missing.join(", ")}`);
    if (r.extra.length) console.log(`     DƯ      : ${r.extra.join(", ")}`);
  }
  const ok = rows.filter((r) => r.ok).length;
  console.log(`\n${ok}/${rows.length} khớp mô hình · tổng chi phí ${cost.toFixed(4)} USD`);
}

11. Áp vào máy mình

  • ~/.claude/CLAUDE.md trên máy mình đang chứa hướng dẫn cá nhân về cách dùng một công cụ chat nội bộ. Đây là đúng chỗ: sở thích và công cụ riêng của mình, team không cần.
  • Nếu một quy ước của cả team (cách đặt tên, quy trình review) đang nằm ở đó thì phải chuyển vào CLAUDE.md của repo, không thì đồng nghiệp clone về sẽ không có.
  • Ghi chú riêng cho một repo (sandbox URL, dữ liệu test ưa dùng) thì để trong CLAUDE.local.md và thêm vào .gitignore.

12. Tiêu chí hoàn thành

  • Project-level .claude/CLAUDE.md có naming (qua import), error handling, checklist review
  • packages/api/CLAUDE.md có quy ước REST và schema
  • .claude/rules/testing.md có 3 quy ước
  • Dòng import bắt đầu bằng @, file đích tồn tại, đường dẫn tính đúng từ file chứa import
  • Bảng "đứng ở đâu nạp gì" cho 3 thư mục và trường hợp on-demand (mô hình; chờ đối chiếu thật)
  • Bước 6 có script thêm/gỡ khối user-level an toàn, và phiên "người mới" không có user-level (chờ chạy thật)

13. Bài học rút ra

  • 3 cấp: user (~/.claude/CLAUDE.md, cá nhân, không qua git) · project (.claude/CLAUDE.md hoặc CLAUDE.md gốc, commit, cả team) · thư mục (packages/api/CLAUDE.md, chỉ khi làm trong thư mục đó). CLAUDE.local.md là bản cá nhân theo repo.
  • Không có precedence giữa các CLAUDE.md: tất cả được nối vào context. Quy tắc phải luôn đúng → settings.json hoặc hook.
  • @đường/dẫn (không có từ khoá @import), tương đối với file chứa nó, nạp ngay: tách file cho dễ sửa chứ không giảm context. Muốn giảm context → rule có paths (bài 3.3).
  • /memory và /context chỉ để xem, không nạp gì.

Ba bẫy đề

  1. Người mới clone cùng repo, cùng branch mà Claude không theo quy ước → quy ước nằm ở user-level, chuyển vào project.
  2. "Chạy /memory để nạp cấu hình" → sai, file tự nạp theo vị trí.
  3. Quy ước áp cho file rải rác nhiều thư mục (vd mọi file test) mà dùng CLAUDE.md cấp thư mục → dùng .claude/rules/ với glob paths.
