Domain 2 · Tool Design & MCP Integration · Mục 2.4 MCP Server Integration
Người thực hiện: TruongNQ · Ngày nộp: 14/10/2026

1. Mục tiêu

Cấu hình MCP server ở hai mức: project (.mcp.json trong repo, chia sẻ cho team) và user (~/.claude.json, cá nhân). Giữ credential ngoài git bằng ${VAR}. Đưa schema DB ra thành resource để agent khỏi phải gọi tool dò từng bảng. Viết mô tả tool đủ tốt để Claude chọn tool MCP thay vì Grep/Read built-in.

2. Sơ đồ

Đề thi (exam guide v1.0) dùng 2 mức như hình. Claude Code hiện có 3 scope: local (mặc định, riêng bạn trong một project), project và user; local và user đều lưu trong ~/.claude.json (claude mcp add --help: “-s, --scope … (local, user, or project) (default: "local")”).

3. Năm bước ↔ cách hiện thực

#Yêu cầuHiện thực
1.mcp.json ở gốc project, dùng server chính thức cho tích hợp chuẩndemo-project/.mcp.json: github là server remote chính thức của GitHub (type: "http", url: https://api.githubcopilot.com/mcp/) — không tự viết; crm-db là server local tự viết (command + args) vì DB nội bộ không có server cộng đồng
2Credential qua biến môi trường"Authorization": "Bearer ${GITHUB_TOKEN}"; ${CRM_DB_URL:-sqlite://./crm.db} minh hoạ default. .env.example + .gitignore chặn .env. check_config.ts và secret_guard.sh bắt token viết cứng
3Server cá nhân ở ~/.claude.jsonsetup_user_scope.sh: mặc định chỉ in lệnh claude mcp add --scope user crm-db-experimental …; --apply mới chạy, --remove --apply để gỡ. Không tự sửa config của máy
4Resource catalogue nội dungcrm_db_server.ts khai báo db://schema/main (name, description, application/json): 4 bảng, cột + kiểu + khoá ngoại, quan hệ. lib/mcp_server.ts được mở rộng thêm resources/list, resources/read (tương thích ngược)
5Mô tả tool 3–5 câu, so với built-inDESC=clear: mỗi tool 4–5 câu (làm gì, trả gì, khi nào dùng, vì sao thay Grep/Bash). DESC=sparse: 1 câu (“Searches data.”) để đối chiếu

Env var expansion: ${VAR} lấy từ môi trường của người chạy claude; ${VAR:-mặc định} dùng giá trị mặc định khi biến chưa đặt. File chỉ chứa tên biến nên commit an toàn, mỗi dev dùng token của mình, đổi token không phải sửa config.

Biến thiếu chỉ là CẢNH BÁO. Đã kiểm chứng thật (mục 8): thiếu GITHUB_TOKEN thì claude mcp list chỉ in [Warning] … Missing environment variables: GITHUB_TOKEN và vẫn nạp config. Token thiếu sẽ không “kêu” lỗi, nên phải tự kiểm (check_config.ts).

6. Mô tả tool: sparse và clear

ToolDESC=sparseDESC=clear
query_matching_projectsSearches data.Truy vấn bảng matching_projects của DB CRM theo ngành nghề (trade), trạng thái (status) và ngân sách tối thiểu. Trả về JSON gồm id, title, trade, budget_jpy, status và owner_company đã join sẵn từ users. Dùng khi câu hỏi về DỮ LIỆU dự án đang có trong hệ thống (vd 'dự án điện nào đang mở trên 1 triệu yên'). Nên dùng tool này thay cho Grep/Read: dữ liệu nằm trong DB chứ không nằm trong file mã nguồn, và thay cho Bash + sqlite vì tool đã chặn câu lệnh ghi và tự join bảng. Muốn biết DB có bảng/cột gì thì đọc resource db://schema/main trước.
find_userGets a user.Tìm MỘT người dùng CRM theo email hoặc id, trả về id, email, company_name, role, prefecture. Dùng khi cần biết ai sở hữu dự án hoặc thông tin một nhà thầu. Không tìm được thì trả resultCount 0 (không phải lỗi, không cần gọi lại). Không dùng Grep để tìm người dùng: email thật nằm trong DB, không có trong repo.

Lý do: built-in như Grep có mô tả rất dài và rõ. Tool MCP mô tả một câu sẽ “thua” — Claude đi Grep mã nguồn (demo-project/src/ có nhắc tên bảng) thay vì hỏi DB.

7. Mã nguồn

TypeScript, chạy bằng node --experimental-strip-types --no-warnings (Node ≥ 22.6). Server dùng lib/mcp_server.ts chung của repo.

function logCall(name: string, args: Record<string, unknown>): void {
  const log = process.env.CRM_LOG;

      },
    },

check_config.ts
// Bài 2.4 – kiểm tĩnh một file .mcp.json trước khi commit.
//
//   LỖI (exit 1):   thiếu mcpServers · entry có url mà thiếu type http/sse · entry local thiếu command/args
//                   · giá trị trông như secret thật (ghp_, github_pat_, sk-, xoxb-, AKIA…, "Bearer <chuỗi dài>")
//   CẢNH BÁO:       biến ${VAR} không có default và chưa đặt trong env hiện tại. Giống Claude Code: chỉ cảnh báo,
//                   không dừng nạp config → token thiếu sẽ không "kêu" lỗi, phải tự kiểm.
//
// Chạy:  node --experimental-strip-types --no-warnings check_config.ts demo-project/.mcp.json
import { readFileSync } from "node:fs";
import { pathToFileURL } from "node:url";

export interface Finding {
  level: "error" | "warn" | "info";
  where: string;
  message: string;
}

const SECRET_PATTERNS: [RegExp, string][] = [
  [/\bghp_[A-Za-z0-9_]{16,}/, "GitHub personal access token (ghp_…)"],
  [/\bgithub_pat_[A-Za-z0-9_]{16,}/, "GitHub fine-grained token (github_pat_…)"],
  [/\bsk-[A-Za-z0-9_-]{16,}/, "API key dạng sk-…"],
  [/\bxox[abp]-[A-Za-z0-9-]{10,}/, "Slack token"],
  [/\bAKIA[0-9A-Z]{16}\b/, "AWS access key"],
  [/Bearer\s+(?!\$\{)[A-Za-z0-9._~+\/-]{20,}/, "Bearer token viết cứng"],
];

const VAR_RE = /\$\{([A-Za-z_][A-Za-z0-9_]*)(:-([^}]*))?\}/g;

export interface VarRef {
  name: string;
  default?: string;
  where: string;
}

/** Duyệt mọi chuỗi trong object, gọi fn(chuỗi, đường dẫn). */
function walkStrings(v: unknown, path: string, fn: (s: string, path: string) => void): void {
  if (typeof v === "string") fn(v, path);
  else if (Array.isArray(v)) v.forEach((x, i) => walkStrings(x, `${path}[${i}]`, fn));
  else if (v && typeof v === "object") for (const [k, x] of Object.entries(v)) walkStrings(x, `${path}.${k}`, fn);
}

/** Mở rộng ${VAR} và ${VAR:-default} giống Claude Code (biến thiếu, không default → giữ nguyên chuỗi). */
export function expand(s: string, env: Record<string, string | undefined>): string {
  return s.replace(VAR_RE, (whole, name: string, _d, def: string | undefined) =>
    env[name] !== undefined && env[name] !== "" ? env[name]! : def !== undefined ? def : whole,
  );
}

export function checkConfig(config: unknown, env: Record<string, string | undefined> = process.env): {
  findings: Finding[];
  vars: VarRef[];
} {
  const findings: Finding[] = [];
  const vars: VarRef[] = [];
  const servers = (config as { mcpServers?: Record<string, Record<string, unknown>> } | null)?.mcpServers;
  if (!servers || typeof servers !== "object") {
    findings.push({ level: "error", where: "(root)", message: "Thiếu object mcpServers" });
    return { findings, vars };
  }
  if (Object.keys(servers).length === 0) findings.push({ level: "error", where: "mcpServers", message: "Không có server nào" });

  for (const [name, entry] of Object.entries(servers)) {
    const where = `mcpServers.${name}`;
    const type = entry.type as string | undefined;
    if (entry.url !== undefined) {
      if (type !== "http" && type !== "sse" && type !== "ws")
        findings.push({
          level: "error",
          where,
          message: `Có url nhưng ${type === undefined ? "thiếu" : `type="${type}" sai,`} type: "http" (hoặc "sse"/"ws"). Claude Code sẽ coi là stdio và bỏ qua server này`,
        });
      else findings.push({ level: "info", where, message: `Remote server (${type}) → ${entry.url}` });
    } else {
      if (typeof entry.command !== "string" || !entry.command)
        findings.push({ level: "error", where, message: "Local (stdio) server thiếu command" });
      if (entry.args !== undefined && !Array.isArray(entry.args))
        findings.push({ level: "error", where, message: "args phải là mảng" });
      else if (entry.args === undefined)
        findings.push({ level: "warn", where, message: "Local server không có args (hợp lệ nếu command tự đủ)" });
      if (typeof entry.command === "string") findings.push({ level: "info", where, message: `Local server (stdio) → ${entry.command}` });
    }

    walkStrings(entry, where, (s, path) => {
      for (const [re, label] of SECRET_PATTERNS)
        if (re.test(s)) findings.push({ level: "error", where: path, message: `Có vẻ là secret viết cứng: ${label}. Dùng \${VAR} thay thế` });
      for (const m of s.matchAll(VAR_RE)) vars.push({ name: m[1]!, default: m[3], where: path });
    });
  }

  for (const v of vars) {
    const set = env[v.name] !== undefined && env[v.name] !== "";
    if (!set && v.default === undefined)
      findings.push({
        level: "warn",
        where: v.where,
        message: `\${${v.name}} chưa đặt và không có default → Claude Code chỉ cảnh báo, giá trị sẽ hỏng (vd header "Bearer \${${v.name}}")`,
      });
    else if (!set)
      findings.push({ level: "info", where: v.where, message: `\${${v.name}} chưa đặt → dùng default "${v.default}"` });
  }
  return { findings, vars };
}

if (import.meta.url === pathToFileURL(process.argv[1] ?? "").href) {
  const file = process.argv[2] ?? ".mcp.json";
  const { findings, vars } = checkConfig(JSON.parse(readFileSync(file, "utf8")));
  console.log(`Kiểm ${file}`);
  const icon = { error: "✗ LỖI     ", warn: "! CẢNH BÁO", info: "· info    " };
  for (const f of findings) console.log(`${icon[f.level]} ${f.where}: ${f.message}`);
  console.log(`Biến môi trường dùng: ${vars.map((v) => (v.default !== undefined ? `${v.name} (mặc định ${v.default})` : v.name)).join(", ") || "(không có)"}`);
  const errors = findings.filter((f) => f.level === "error").length;
  const warns = findings.filter((f) => f.level === "warn").length;
  console.log(`→ ${errors} lỗi, ${warns} cảnh báo`);
  process.exitCode = errors ? 1 : 0;
}
secret_guard.sh
#!/usr/bin/env bash
# Bài 2.4 – chặn commit secret: quét các dòng ĐƯỢC THÊM trong `git diff --cached` (mặc định)
# hoặc toàn bộ nội dung các file truyền vào. Có secret → in vị trí, exit 1.
#
# Dùng:  ./secret_guard.sh                 # trong một git repo, sau khi git add
#        ./secret_guard.sh file1 file2     # quét file bất kỳ
# Gắn làm pre-commit hook:  ln -s "$(pwd)/secret_guard.sh" .git/hooks/pre-commit
set -euo pipefail

# Cùng bộ mẫu với check_config.ts. "${VAR}" là placeholder hợp lệ, không bị coi là secret.
PATTERN='ghp_[A-Za-z0-9_]{16,}|github_pat_[A-Za-z0-9_]{16,}|sk-[A-Za-z0-9_-]{16,}|xox[abp]-[A-Za-z0-9-]{10,}|AKIA[0-9A-Z]{16}|Bearer[[:space:]]+[A-Za-z0-9._~+/-]{20,}'

if [[ $# -gt 0 ]]; then
  hits="$(grep -nHE "$PATTERN" "$@" || true)"
else
  # Chỉ lấy dòng thêm mới (+), bỏ header "+++ b/file"; giữ tên file để báo vị trí.
  hits="$(git diff --cached --unified=0 --no-color | awk '
    /^\+\+\+ b\// { file = substr($0, 7); next }
    /^@@/ { split($3, a, ","); line = substr(a[1], 2) + 0; next }
    /^\+/ { print file ":" line ":" substr($0, 2); line++ }
  ' | grep -E "$PATTERN" || true)"
fi

if [[ -n "$hits" ]]; then
  echo "✗ Phát hiện giá trị trông như secret (dùng \${VAR} trong .mcp.json, để giá trị thật trong .env/shell):"
  echo "$hits" | sed 's/^/  /'
  exit 1
fi
echo "✓ Không thấy secret"

#!/usr/bin/env bash
# Bài 2.4 – bước 3: thêm một server CÁ NHÂN / thử nghiệm ở user scope (~/.claude.json, ngoài repo).
# Mặc định chỉ IN lệnh (dry-run). Không tự sửa ~/.claude.json của bạn.
#
# Dùng:  ./setup_user_scope.sh            # in lệnh add sẽ chạy
#        ./setup_user_scope.sh --apply    # chạy thật: claude mcp add --scope user …
#        ./setup_user_scope.sh --remove   # in lệnh gỡ; thêm --apply để gỡ thật
#        ./setup_user_scope.sh --check    # claude mcp get <tên> (health check, không gọi model)

# Server mẫu: crm-db bản thử nghiệm với mô tả sparse, chỉ mình bạn thấy, mọi project đều dùng được.
# Muốn chia sẻ cho team thì KHÔNG dùng user scope, mà khai báo trong .mcp.json của repo (demo-project/).
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
CLAUDE="${CLAUDE_BIN:-claude}"
NAME="${SERVER_NAME:-crm-db-experimental}"
NODE="$(command -v node)"

ADD=("$CLAUDE" mcp add --scope user "$NAME"
     -e DESC=sparse -e "CRM_DB_URL=sqlite://$HOME/.local/share/crm-experimental.db"
     -- "$NODE" --experimental-strip-types --no-warnings "$ROOT/crm_db_server.ts")

for a in "$@"; do
  case "$a" in
    --apply) apply=1 ;;
    --remove) mode=remove ;;
    --check) mode=check ;;
    *) echo "Tham số lạ: $a"; sed -n '2,10p' "$0"; exit 1 ;;
  esac
done

show() { printf '  %q' "$@"; echo; }
case "$mode" in
  add)    cmd=("${ADD[@]}") ;;
  remove) cmd=("${REMOVE[@]}") ;;
  check)  "${GET[@]}"; exit $? ;;
esac

if [[ "$apply" == 1 ]]; then
  echo "▶ Chạy:"; show "${cmd[@]}"
  "${cmd[@]}"
  if [[ "$mode" == add ]]; then echo "Gỡ lại bằng: $0 --remove --apply"; fi
else
  echo "(dry-run) Lệnh sẽ chạy — thêm --apply để chạy thật:"; show "${cmd[@]}"

#!/usr/bin/env bash
# Bài 2.4 – PHẦN TUỲ CHỌN (chưa chạy): xem Claude chọn tool MCP hay tool built-in (Grep/Read)
# khi mô tả tool MCP sơ sài (DESC=sparse) so với mô tả đầy đủ (DESC=clear).
#
# Dùng:  ./run_cli.sh sparse | clear | all     mỗi câu hỏi một lệnh `claude -p` riêng (haiku)
#        ./run_cli.sh report                   bảng: tool nào được gọi, bao nhiêu lần, có đọc resource không
#        ./run_cli.sh clean
#
# Chi phí ước tính (haiku): 2 câu × 2 kiểu = 4 lệnh, mỗi lệnh 1–6 lượt. Bài 2.1 tốn ~0,002 USD/lệnh,
# bài này có thêm tool built-in nên ước ~0,01–0,05 USD tổng; mỗi lệnh chặn trần --max-budget-usd.
#
# Chạy trong demo-project/ (có mã nguồn giả để Grep "cạnh tranh") nhưng KHÔNG dùng .mcp.json của project
# (cần duyệt và GITHUB_TOKEN): cấu hình crm-db được sinh riêng và nạp bằng --mcp-config --strict-mcp-config.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT="$ROOT/demo-project"
RESULTS="${RESULTS_DIR:-$ROOT/results_cli}"
MODEL="${MODEL:-haiku}"
BUDGET="${BUDGET:-0.2}"
CLAUDE_BIN="${CLAUDE_BIN:-claude}"
TS=(node --experimental-strip-types --no-warnings)

QUESTIONS=(
  "Trong hệ thống CRM hiện có dự án ngành điện nào đang mở với ngân sách từ 1 triệu yên trở lên? Chủ dự án là công ty nào?"
  "Bảng favorites trong DB CRM có những cột nào và liên kết với bảng nào?"
)

run_style() {
  local style="$1" dir="$RESULTS/$1" i mcp
  mkdir -p "$dir"
  mcp="$dir/mcp.json"
  node -e 'const [node, srv, desc, log] = process.argv.slice(1);
    console.log(JSON.stringify({ mcpServers: { "crm-db": { type: "stdio", command: node,
      args: ["--experimental-strip-types", "--no-warnings", srv],
      env: { DESC: desc, CRM_DB_URL: "sqlite://./crm.db", CRM_LOG: log } } } }, null, 2))' \
    "$(command -v node)" "$ROOT/crm_db_server.ts" "$style" "$dir/calls.log" > "$mcp"
  echo "== DESC=$style, model=$MODEL"
  for i in "${!QUESTIONS[@]}"; do
    echo "  q$i: ${QUESTIONS[$i]}"
    # Cho phép cả tool built-in (Read/Grep/Glob) lẫn tool MCP và 2 tool đọc resource của Claude Code,
    # để xem model chọn bên nào. (Tên ListMcpResourcesTool/ReadMcpResourceTool: chưa kiểm chứng với --tools.)
    (cd "$PROJECT" && "$CLAUDE_BIN" -p "${QUESTIONS[$i]}" \
      --model "$MODEL" \
      --mcp-config "$mcp" --strict-mcp-config \
      --tools Read Grep Glob ListMcpResourcesTool ReadMcpResourceTool \
      --allowedTools Read Grep Glob ListMcpResourcesTool ReadMcpResourceTool \
                     "mcp__crm-db__query_matching_projects" "mcp__crm-db__find_user" \
      --permission-mode dontAsk \
      --max-budget-usd "$BUDGET" \
      --no-session-persistence \
      --output-format stream-json --verbose \
      > "$dir/q$i.jsonl" 2> "$dir/q$i.err") || echo "    (lệnh trả mã lỗi, xem $dir/q$i.err)"
  done
}

case "${1:-}" in
  sparse|clear) run_style "$1" ;;
  all)    run_style sparse; run_style clear; "${TS[@]}" "$ROOT/report_cli.ts" "$RESULTS" ;;
  report) "${TS[@]}" "$ROOT/report_cli.ts" "$RESULTS" ;;
  clean)  rm -rf "$RESULTS" ;;
  *) sed -n '2,8p' "$0"; exit 1 ;;
esac
report_cli.ts
// Bài 2.4 – đọc results_cli/<style>/q*.jsonl, in tool nào được gọi theo thứ tự và tổng theo nhóm
// (MCP / built-in / đọc resource), để so DESC=sparse với DESC=clear.
import { readdirSync, existsSync } from "node:fs";
import { join } from "node:path";
import { readStream, toolUses, resultEvent } from "../lib/cli_stream.ts";

const results = process.argv[2] ?? "results_cli";
const kind = (name: string) =>
  name.startsWith("mcp__") ? "mcp" : /McpResource/.test(name) ? "resource" : "built-in";

for (const style of ["sparse", "clear"]) {
  const dir = join(results, style);
  if (!existsSync(dir)) continue;
  const total = { mcp: 0, "built-in": 0, resource: 0 } as Record<string, number>;
  let cost = 0;
  console.log(`\n== DESC=${style}`);
  for (const f of readdirSync(dir).filter((f) => /^q\d+\.jsonl$/.test(f)).sort()) {
    const ev = readStream(join(dir, f));
    const uses = toolUses(ev);
    for (const u of uses) total[kind(u.name)]!++;
    cost += Number(resultEvent(ev)?.total_cost_usd ?? 0);
    const seq = uses.map((u) => u.name.replace("mcp__crm-db__", "mcp:")).join(" → ") || "(không gọi tool)";
    console.log(`  ${f.replace(".jsonl", "")}: ${uses.length} lần gọi · ${seq}`);
  }
  console.log(`  Tổng: MCP ${total.mcp}, built-in ${total["built-in"]}, đọc resource ${total.resource} · chi phí $${cost.toFixed(4)}`);
}

10. Áp vào máy mình

  • backlog đang khai báo ở user scope (~/.claude.json), nên chỉ máy mình có. Nếu cả team dùng Backlog thì nên chuyển sang .mcp.json của repo, token qua ${BACKLOG_API_KEY} (domain cũng có thể là biến), mỗi người tự đặt giá trị của mình.
  • Connector claude.ai (Google Drive, Figma, Notion…) là nguồn thứ ba: cấu hình trên tài khoản claude.ai, không nằm trong .mcp.json hay ~/.claude.json. claude mcp list hiện chúng với tiền tố claude.ai.
  • GitHub, Backlog đều đã có server sẵn → dùng, không tự viết. Chỉ tự viết cho hệ thống nội bộ không có server (như crm-db ở đây).

11. Tiêu chí hoàn thành

  • .mcp.json ở gốc project có mcpServers; remote có type + url, local có command + args
  • Xác thực dùng placeholder ${GITHUB_TOKEN}; secret_guard.sh trên git diff --cached không thấy secret
  • Server cá nhân ở ~/.claude.json, ngoài repo (script sẵn, chạy bằng --apply)
  • Resource db://schema/main có name, description, MIME type, nội dung là bảng + cột + kiểu
  • Mô tả tool 3–5 câu, nói rõ vì sao dùng thay built-in

12. Bài học rút ra

  • Team dùng chung → .mcp.json (commit vào git). Cá nhân / thử nghiệm → ~/.claude.json.
  • Không bao giờ viết token vào .mcp.json: dùng ${VAR}, giá trị để trong shell/.env/secrets manager.
  • Tích hợp chuẩn (GitHub, Jira, Slack, Linear, Notion) → dùng server có sẵn trước; tự viết chỉ khi có logic/hệ thống riêng.
  • Resource cho biết “có gì”, tool để “làm gì”: schema dạng resource giúp bớt lượt gọi tool dò dẫm.
  • Mô tả MCP sơ sài thua built-in: viết mô tả nói rõ trả gì và khi nào nên dùng thay Grep.

Bẫy đề

  1. Tự viết MCP server cho tích hợp chuẩn (vd Jira) → sai, phải xem server cộng đồng trước.
  2. Đặt server cả team dùng vào ~/.claude.json → sai, file đó cá nhân, không chia sẻ.
  3. Viết cứng token vào .mcp.json → sai, dùng ${VAR}.
  4. Để mô tả MCP sơ sài → agent chọn tool built-in.
