1. Mục tiêu

Thay mọi lời gọi hàm deprecated processLegacyOrder(orderId) bằng processOrder(orderId, { validate: true }) trong một codebase TypeScript 33 file, đúng tool, đúng thứ tự, tốn ít context:

  • Grep tìm nội dung (caller).
  • Glob tìm đường dẫn (file test).
  • Read chỉ những file đã được chỉ ra là liên quan.
  • Edit từng chỗ, và xử lý được lỗi non-unique match.

Codebase mẫu có cài sẵn bẫy (barrel đổi tên, wrapper, hai dòng trùng nhau, file tên “legacy” nhưng không liên quan) và có đáp án, nên có thể chấm tự động hai việc: chuỗi tool Claude đã chọn, và kết quả refactor.

5. Grep vs Glob, Edit và non-unique

GrepGlob
Tìm trongNội dung fileTên / đường dẫn file
Câu hỏi“File nào chứa X?”“File nào tên giống X?”
Ví dụCaller của hàm, chuỗi lỗi, import utils/auth**/*.test.tsx, **/config.*
Dùng saiTìm file test theo tên (chạy được nhưng không phải tool đúng)Tìm caller: không bao giờ đúng, Glob không nhìn vào trong file

Edit chỉ sửa đúng đoạn old_string → new_string, nên tốn ít context. Nếu old_string khớp nhiều chỗ, Edit từ chối đoán. Thông báo thật của Claude Code 2.1.299, lấy từ binary:

Found 2 matches of the string to replace, but replace_all is false. To replace all occurrences, set replace_all to true. To replace only one occurrence, please provide more context to uniquely identify the instance.
Sau khi Edit báo non-uniqueKhi nào
Đáp án đề thi: Read cả file rồi Write bản đã sửaLuôn chạy được, nhưng nạp token của cả file cho một thay đổi nhỏ. Đây là fallback
Thực tế (docs Edit hiện tại): mở rộng old_string thêm dòng xung quanhChỉ muốn sửa một chỗ
Thực tế: replace_all: trueMuốn sửa mọi chỗ (như bulk_reprocess.ts)

Thứ tự nên làm: Edit với anchor ngắn mà có vẻ duy nhất → bị non-unique thì mở rộng hoặc dùng replace_all → không phân biệt được nữa mới Read + Write. Nhưng đề hỏi bước tiếp theo sau non-unique thì chọn Read + Write.

#!/usr/bin/env bash
# Bài 2.5 – để Claude Code (CLI thật) tự lần theo và refactor hàm deprecated, rồi chấm chuỗi tool nó đã chọn.
#
# Dùng:  ./run_cli.sh reset     copy sample/ → .work/ (bản gốc không bao giờ bị sửa)
#        ./run_cli.sh run       claude -p trong .work/, ghi results/run.jsonl
#        ./run_cli.sh analyze   in chuỗi tool + chấm tiêu chí (Grep trước, Glob tìm test, Edit, non-unique…)
#        ./run_cli.sh verify    chạy test của codebase trong .work/ + kiểm không còn lời gọi deprecated
#        ./run_cli.sh all       reset → run → analyze → verify
#        ./run_cli.sh clean
#
# Biến môi trường:
#   MODEL (mặc định sonnet) · BUDGET (USD, mặc định 1) · CLAUDE_BIN (mặc định claude)
#   ALLOW_WRITE=1  cho phép thêm tool Write (mặc định KHÔNG: buộc sửa bằng Edit, quan sát cách xử lý non-unique)
#   SEARCH=bash    nếu bản Claude Code không có Grep/Glob riêng: cho Bash nhưng chỉ lệnh grep/rg/find (read-only)
#   WORK_DIR, OUT_DIR  (test dùng thư mục tạm)
# Chi phí ước tính: sonnet, ~15–25 lượt tool → khoảng 0,1–0,5 USD; bị chặn trần bằng --max-budget-usd.
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
WORK="${WORK_DIR:-$ROOT/.work}"
OUT="${OUT_DIR:-$ROOT/results}"
MODEL="${MODEL:-sonnet}"
BUDGET="${BUDGET:-1}"
CLAUDE="${CLAUDE_BIN:-claude}"
TS=(node --experimental-strip-types --no-warnings)

# Prompt KHÔNG gợi ý tool nào: để quan sát Claude tự chọn Grep/Glob/Read/Edit.
PROMPT="Hàm processLegacyOrder(orderId) trong src/orders/legacy.ts đã deprecated. \
Hãy chuyển MỌI nơi đang dùng nó sang API mới processOrder(orderId, { validate: true }) trong src/orders/process.ts, \
kể cả những nơi dùng gián tiếp (qua hàm bọc hoặc qua tên khác do re-export). \
Giữ nguyên src/orders/legacy.ts và test của chính nó. \
Cuối cùng liệt kê các file đã sửa và các file test liên quan tới những chỗ đã sửa."

cmd_reset() {
  rm -rf "$WORK"
  mkdir -p "$(dirname "$WORK")"
  cp -r "$ROOT/sample" "$WORK"
  echo "Đã tạo $WORK từ sample/ ($(find "$WORK" -type f | wc -l) file)"
}

cmd_run() {
  [[ -d "$WORK" ]] || cmd_reset
  mkdir -p "$OUT"
  local tools=(Read Grep Glob Edit) allow
  [[ "${SEARCH:-}" == bash ]] && tools=(Read Edit Bash)
  [[ "${ALLOW_WRITE:-0}" == 1 ]] && tools+=(Write)
  local IFS=,
  allow=("${tools[@]}")
  # Bash (nếu bật) chỉ được chạy lệnh tìm kiếm read-only.
  [[ "${SEARCH:-}" == bash ]] && allow=(Read Edit "Bash(grep:*)" "Bash(rg:*)" "Bash(find:*)" "Bash(ls:*)") && [[ "${ALLOW_WRITE:-0}" == 1 ]] && allow+=(Write)
  echo "▶ claude -p (model=$MODEL, tools=${tools[*]}) trong $WORK"
  (cd "$WORK" && "$CLAUDE" -p "$PROMPT" \
    --model "$MODEL" \
    --tools "${tools[*]}" \
    --allowedTools "${allow[@]}" \
    --permission-mode dontAsk \
    --safe-mode \
    --max-budget-usd "$BUDGET" \
    --no-session-persistence \
    --output-format stream-json --verbose \
    > "$OUT/run.jsonl" 2> "$OUT/run.err") || echo "  (claude trả mã lỗi, xem $OUT/run.err)"
  echo "  → $OUT/run.jsonl ($(wc -l < "$OUT/run.jsonl") event)"
}

cmd_analyze() { "${TS[@]}" "$ROOT/analyze_tools.ts" "$OUT/run.jsonl" "$WORK"; }
cmd_verify()  { "${TS[@]}" "$ROOT/verify.ts" "$WORK"; }

case "${1:-}" in
  reset|run|verify) "cmd_$1" ;;
  analyze) cmd_analyze || true ;;
  all) cmd_reset; cmd_run; cmd_analyze || true; echo; cmd_verify ;;
  clean) rm -rf "$WORK" "$OUT" ;;
  *) sed -n '2,19p' "$0"; exit 1 ;;
esac
analyze_tools.ts
// Đọc stream-json của `claude -p` (bài 2.5) → in chuỗi tool theo thứ tự và chấm theo tiêu chí của đề.
//   node --experimental-strip-types analyze_tools.ts <run.jsonl> [thư-mục-làm-việc]
//
// Bản Claude Code có thể không có tool Grep/Glob riêng (tìm kiếm qua Bash + grep/find), nên lệnh Bash
// grep/rg/ugrep được tính là "tìm nội dung", find/fd/ls là "tìm đường dẫn".
import { readdirSync } from "node:fs";
import { join, relative, isAbsolute } from "node:path";
import { readStream, resultEvent, type StreamEvent } from "../lib/cli_stream.ts";
import { CALLER_GROUPS } from "./refactor_reference.ts";

export type Kind = "content-search" | "path-search" | "read" | "edit" | "write" | "other";

export interface Step {
  n: number;
  tool: string;
  kind: Kind;
  summary: string; // pattern / đường dẫn rút gọn
  file?: string; // tương đối so với thư mục làm việc
  isError: boolean;
  resultText: string;
  input: Record<string, any>;
}

export interface Criterion {
  id: string;
  label: string;
  ok: boolean | null; // null = không áp dụng / chỉ quan sát
  detail: string;
}

const NON_UNIQUE = /Found \d+ matches of the string to replace|replace_all is false|more context to uniquely/i;

function classify(name: string, input: Record<string, any>): { kind: Kind; summary: string } {
  if (name === "Grep") return { kind: "content-search", summary: `${input.pattern}${input.glob ? ` (glob ${input.glob})` : ""}` };
  if (name === "Glob") return { kind: "path-search", summary: String(input.pattern) };
  if (name === "Read") return { kind: "read", summary: String(input.file_path) };
  if (name === "Edit") return { kind: "edit", summary: String(input.file_path) };
  if (name === "Write") return { kind: "write", summary: String(input.file_path) };
  if (name === "Bash") {
    const cmd = String(input.command ?? "").trim();
    if (/^(grep|rg|ugrep|git\s+grep)\b/.test(cmd)) return { kind: "content-search", summary: `$ ${cmd}` };
    if (/^(find|fd|ls)\b/.test(cmd)) return { kind: "path-search", summary: `$ ${cmd}` };
    return { kind: "other", summary: `$ ${cmd}` };
  }
  return { kind: "other", summary: JSON.stringify(input).slice(0, 80) };
}

const textOf = (c: unknown): string =>
  typeof c === "string" ? c : Array.isArray(c) ? c.map((b: any) => b?.text ?? "").join("\n") : JSON.stringify(c ?? "");

export function steps(events: StreamEvent[], workDir: string): Step[] {
  const results = new Map<string, { isError: boolean; text: string }>();
  for (const e of events)
    if (e.type === "user" && Array.isArray(e.message?.content))
      for (const b of e.message!.content)
        if (b.type === "tool_result") results.set(b.tool_use_id, { isError: b.is_error === true, text: textOf(b.content) });

  const out: Step[] = [];
  for (const e of events) {
    if (e.type !== "assistant" || !Array.isArray(e.message?.content)) continue;
    for (const b of e.message!.content) {
      if (b.type !== "tool_use") continue;
      const { kind, summary } = classify(b.name, b.input ?? {});
      const r = results.get(b.id) ?? { isError: false, text: "" };
      const fp = b.input?.file_path as string | undefined;
      const file = fp ? (isAbsolute(fp) ? relative(workDir, fp) : fp.replace(/^\.\//, "")) : undefined;
      out.push({ n: out.length + 1, tool: b.name, kind, summary, file, isError: r.isError, resultText: r.text, input: b.input ?? {} });
    }
  }
  return out;
}

export function countFiles(dir: string): number {
  return (readdirSync(dir, { recursive: true, withFileTypes: true }) as any[]).filter((d) => d.isFile()).length;
}

export function grade(st: Step[], totalFiles: number): Criterion[] {
  const searches = st.filter((s) => s.kind === "content-search" || s.kind === "path-search");
  const first = searches[0];
  const readsBeforeFirst = first ? st.filter((s) => s.kind === "read" && s.n < first.n).length : st.filter((s) => s.kind === "read").length;
  const readFiles = new Set(st.filter((s) => s.kind === "read" && s.file).map((s) => s.file!));
  const content = st.filter((s) => s.kind === "content-search");
  const editedOk = new Set(st.filter((s) => s.kind === "edit" && !s.isError && s.file).map((s) => s.file!));
  const missing = CALLER_GROUPS.filter((g) => !g.some((f) => editedOk.has(f)));
  const writes = st.filter((s) => s.kind === "write");

  // Edit lỗi non-unique rồi thử lại thành công trên cùng file
  const nonUnique = st.filter((s) => s.kind === "edit" && s.isError && NON_UNIQUE.test(s.resultText));
  const recovered = nonUnique.map((err) => {
    const retry = st.find((s) => s.kind === "edit" && !s.isError && s.file === err.file && s.n > err.n);
    const how = !retry
      ? "chưa thử lại thành công"
      : retry.input.replace_all
        ? "thử lại bằng replace_all: true"
        : String(retry.input.old_string ?? "").length > String(err.input.old_string ?? "").length
          ? "thử lại với old_string dài hơn"
          : "thử lại bằng Edit khác";
    return { err, retry, how };
  });
  const readThenWrite = nonUnique.some((err) => st.some((s) => s.kind === "write" && s.file === err.file && s.n > err.n));

  return [
    {
      id: "C1",
      label: "Tìm kiếm đầu tiên là tìm NỘI DUNG (Grep), không mở đầu bằng Glob hay đọc hàng loạt",
      ok: !!first && first.kind === "content-search" && readsBeforeFirst <= 2,
      detail: first ? `bước ${first.n}: ${first.tool} ${first.summary}; ${readsBeforeFirst} lần Read trước đó` : "không có lần tìm kiếm nào",
    },
    {
      id: "C2",
      label: "Khám phá tăng dần: số file đã Read ≤ 50% tổng số file",
      ok: readFiles.size <= totalFiles * 0.5,
      detail: `${readFiles.size}/${totalFiles} file`,
    },
    {
      id: "C3",
      label: "Lần theo barrel đổi tên: có tìm nội dung 'submitLegacyOrder'",
      ok: content.some((s) => /submitLegacyOrder/.test(s.summary)),
      detail: content.filter((s) => /submitLegacyOrder/.test(s.summary)).map((s) => `bước ${s.n}`).join(", ") || "không thấy",
    },
    {
      id: "C4",
      label: "Lần theo wrapper: có tìm nội dung 'applyLegacyOrder'",
      ok: content.some((s) => /applyLegacyOrder/.test(s.summary)),
      detail: content.filter((s) => /applyLegacyOrder/.test(s.summary)).map((s) => `bước ${s.n}`).join(", ") || "không thấy",
    },
    {
      id: "C5",
      label: "Tìm file test theo ĐƯỜNG DẪN (Glob *.test.*)",
      ok: st.some((s) => s.kind === "path-search" && /test/.test(s.summary)),
      detail: st.filter((s) => s.kind === "path-search").map((s) => `bước ${s.n}: ${s.summary}`).join("; ") || "không có Glob",
    },
    {
      id: "C6",
      label: "Edit thành công ở mọi caller (trực tiếp, wrapper, barrel)",
      ok: missing.length === 0,
      detail: missing.length ? `thiếu: ${missing.map((g) => g.join(" | ")).join(", ")}` : `${editedOk.size} file đã Edit`,
    },
    {
      id: "C7",
      label: "Không dùng Write (Edit là tool sửa mặc định)",
      ok: writes.length === 0,
      detail: writes.length ? writes.map((s) => `bước ${s.n}: ${s.file}`).join(", ") : "0 lần Write",
    },
    {
      id: "O1",
      label: "Quan sát: Edit báo non-unique match rồi xử lý",
      ok: nonUnique.length === 0 ? null : recovered.every((r) => r.retry) || readThenWrite,
      detail:
        nonUnique.length === 0
          ? "không xảy ra (Claude chọn old_string đủ dài ngay từ đầu, hoặc không đụng tới chỗ trùng)"
          : recovered.map((r) => `bước ${r.err.n} lỗi ở ${r.err.file} → ${r.retry ? `bước ${r.retry.n}: ` : ""}${r.how}`).join("; ") +
            (readThenWrite ? "; có dùng Read + Write" : ""),
    },
  ];
}

export function report(events: StreamEvent[], workDir: string, totalFiles: number): { text: string; criteria: Criterion[] } {
  const st = steps(events, workDir);
  const init = events.find((e) => e.type === "system" && e.subtype === "init");
  const tools: string[] = init?.tools ?? [];
  const lines: string[] = [];
  if (init) {
    lines.push(`Tool có trong phiên: ${tools.join(", ") || "(không có)"}`);
    if (!tools.includes("Grep") || !tools.includes("Glob"))
      lines.push("⚠ Phiên này KHÔNG có tool Grep/Glob riêng: tìm kiếm phải đi qua Bash (lệnh grep/find được tính tương đương).");
  }
  lines.push("", "Chuỗi tool:");
  for (const s of st) lines.push(`  ${String(s.n).padStart(2)}. ${s.tool.padEnd(5)} ${(s.file ?? s.summary).slice(0, 90)}${s.isError ? "  ✗ " + s.resultText.slice(0, 70) : ""}`);
  const count = st.reduce<Record<string, number>>((a, s) => ((a[s.tool] = (a[s.tool] ?? 0) + 1), a), {});
  lines.push("", `Đếm: ${Object.entries(count).map(([k, v]) => `${k}×${v}`).join(", ") || "(không có tool nào)"}`);
  const criteria = grade(st, totalFiles);
  lines.push("", "Tiêu chí:");
  for (const c of criteria) lines.push(`  ${c.ok === null ? "--  " : c.ok ? "OK  " : "FAIL"} ${c.id} ${c.label}\n         ${c.detail}`);
  const res = resultEvent(events);
  if (res) lines.push("", `Kết thúc: subtype=${res.subtype}, turns=${res.num_turns}, cost=$${Number(res.total_cost_usd ?? 0).toFixed(4)}`);
  return { text: lines.join("\n"), criteria };
}

if (import.meta.url === `file://${process.argv[1]}`) {

// Kiểm kết quả refactor trong một thư mục (mặc định .work/): test của codebase còn đạt,
// không còn lời gọi/import hàm deprecated ngoài chính nó, mọi caller đã dùng processOrder(…, { validate: true }).

import { readFileSync, readdirSync, existsSync } from "node:fs";

export interface VerifyResult {
  testsOk: boolean;
  testsOutput: string;
  violations: string[]; // "file:dòng: nội dung"
  callersMigrated: { group: string[]; ok: boolean }[];
  notes: string[];
}

const ALLOWED = new Set(["src/orders/legacy.ts", "src/orders/legacy.test.ts"]);
const CALL = /\b(processLegacyOrder|submitLegacyOrder)\s*\(/;
const IMPORT = /^\s*import\b.*\b(processLegacyOrder|submitLegacyOrder)\b/;

export function verify(dir: string): VerifyResult {
  const t = spawnSync(process.execPath, ["--experimental-strip-types", "--no-warnings", "run_tests.ts"], { cwd: dir, encoding: "utf8" });
  const files = (readdirSync(join(dir, "src"), { recursive: true }) as string[])
    .filter((f) => f.endsWith(".ts"))

// Dùng trong test (áp lên bản sao để verify) và trong claude giả (phát stream-json kịch bản "good").
import { readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";

export interface EditCall {
  file_path: string; // tương đối so với thư mục làm việc
  old_string: string;
  new_string: string;
  replace_all?: boolean;
}

// Thông báo thật của Claude Code 2.1.299 khi old_string khớp nhiều chỗ (lấy từ binary, ${n} = số chỗ khớp).
export const nonUniqueMessage = (n: number) =>
  `Found ${n} matches of the string to replace, but replace_all is false. To replace all occurrences, ` +
  `set replace_all to true. To replace only one occurrence, please provide more context to uniquely identify the instance.`;

export function applyEdit(root: string, e: EditCall): { ok: boolean; message: string } {
  const path = join(root, e.file_path);
  const text = readFileSync(path, "utf8");
  const n = text.split(e.old_string).length - 1;
  if (n === 0) return { ok: false, message: "String to replace not found in file." };
  if (n > 1 && !e.replace_all) return { ok: false, message: nonUniqueMessage(n) };
  writeFileSync(path, e.replace_all ? text.split(e.old_string).join(e.new_string) : text.replace(e.old_string, () => e.new_string));
  return { ok: true, message: `The file ${e.file_path} has been updated.` };
}

10. Bài học rút ra

  • Grep tìm nội dung, Glob tìm đường dẫn. Đây là điểm đề thi kiểm tra nhiều nhất của bài.
  • Một lần Grep chưa đủ. Wrapper và barrel đổi tên làm caller không còn nhắc tên gốc. Phải Read chỗ định nghĩa/re-export rồi Grep tiếp tên mới.
  • Grep → Glob → Grep: Grep tìm caller, Glob tìm test cạnh caller (bắt cả test gọi gián tiếp), Grep lại tên wrapper.
  • Edit trước, Read + Write là fallback (đáp án đề thi). Thực tế nên mở rộng old_string hoặc dùng replace_all trước.
  • Khám phá tăng dần: đọc hết file từ đầu là lỗi tốn context nhất.

5 bẫy đề

  1. Dùng Glob để tìm caller.
  2. Dùng Grep để tìm file theo đuôi hoặc mẫu tên (Glob mới là tool đúng).
  3. Đọc hết mọi file từ đầu.
  4. Mặc định Read + Write cho mọi thay đổi.
  5. Đề hỏi bước tiếp theo sau non-unique mà trả lời “mở rộng old_string / replace_all”. Đáp án theo đề là Read + Write.
