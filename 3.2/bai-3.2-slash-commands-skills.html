1. Mục tiêu

Tạo lệnh dùng chung cho team (/review, đi theo git) và skill cá nhân (/brainstorm, chỉ máy mình), cấu hình frontmatter context: fork, allowed-tools, argument-hint, rồi đo được hai điều đề thi hay hỏi: (1) phiên nào thấy lệnh nào, (2) context: fork có thật sự giữ output dài ngoài hội thoại chính không. Kèm một lint bắt các lỗi đặt file hay gặp, trong đó có bẫy .claude/skills/lint.md (file phẳng, không tạo lệnh).

5. Skill, CLAUDE.md hay rules? Đặt ở đâu?

Khi nào dùng gì

  • CLAUDE.md / .claude/rules/: quy ước luôn áp dụng (đặt tên API, format lỗi). Nạp mọi phiên.
  • Skill / command: quy trình theo việc (review, phân tích, deploy checklist). Chỉ description nằm sẵn trong context, thân bài nạp khi gọi.
  • rules có paths:: quy ước cho một loại file (vd test), nạp khi làm việc với file khớp (bài 3.3).

# Phân tích tính năng: $ARGUMENTS

Bạn chạy trong một subagent riêng. Không thấy lịch sử hội thoại chính, nên chỉ dựa vào hướng dẫn này.

1. Dùng Grep và Glob để tìm mọi file liên quan tới "$ARGUMENTS" trong `src/`.
2. Read từng file tìm được, lần theo import một bậc.
3. Ghi chú chi tiết trong lúc đọc (file, hàm, luồng dữ liệu). Phần ghi chú này ở lại trong subagent.
4. Đối chiếu với các rủi ro thường gặp trong [checklist.md](checklist.md).

**Chỉ trả về phiên chính** một bản tóm tắt tối đa 10 dòng:
- 1 dòng mô tả tính năng
- danh sách file chính (tối đa 5)

# Brainstorm: $ARGUMENTS

Bạn chạy trong subagent riêng (context: fork), nên được phép đọc nhiều và ghi chú dài: phần đó không quay về hội thoại chính.

1. Glob và Grep để khoanh vùng code liên quan tới "$ARGUMENTS".
2. Read các file chính, ghi lại điểm mạnh, điểm yếu, chỗ có thể mở rộng.
3. Nghĩ ra 3–5 hướng làm khác nhau.

**Chỉ trả về** bảng 3–5 dòng: Hướng làm | Lợi ích | Rủi ro | File cần sửa.

// Bài 3.2 – đọc skill và command từ một thư mục .claude (project) hoặc ~/.claude (user). Không gọi model.
// Quy tắc (theo code.claude.com/docs/en/skills):
//   - skill = THƯ MỤC có SKILL.md: .claude/skills/<tên>/SKILL.md → /<tên> (field name: đổi được tên)
//   - command = file .md PHẲNG trong .claude/commands/ → /<tên file>
//   - file .md phẳng đặt thẳng trong .claude/skills/ KHÔNG tạo lệnh
//   - skill và command trùng tên: skill thắng
import { existsSync, readdirSync, readFileSync, statSync } from "node:fs";
import { basename, join } from "node:path";

export interface Frontmatter {
  [key: string]: string | undefined;
}

export interface SkillEntry {
  name: string; // tên lệnh, không có dấu "/"
  kind: "skill" | "command";
  file: string;
  frontmatter: Frontmatter;
  body: string;
}

/** Tách YAML frontmatter đơn giản (key: value một dòng, đủ cho bài tập). */
export function parseFrontmatter(text: string): { frontmatter: Frontmatter; body: string } {
  const m = text.match(/^---\r?\n([\s\S]*?)\r?\n---\r?\n?/);
  if (!m) return { frontmatter: {}, body: text };
  const frontmatter: Frontmatter = {};
  for (const line of m[1].split(/\r?\n/)) {
    const kv = line.match(/^([A-Za-z_-]+):\s*(.*)$/);
    if (kv) frontmatter[kv[1]] = kv[2].replace(/^["']|["']$/g, "").trim();
  }
  return { frontmatter, body: text.slice(m[0].length) };
}

/** Danh sách tool trong allowed-tools / disallowed-tools (chấp nhận cách nhau bằng dấu cách hoặc dấu phẩy, hoặc [a, b]). */
export function toolList(value: string | undefined): string[] {
  if (!value) return [];
  return value
    .replace(/^\[|\]$/g, "")
    .split(/[\s,]+/)
    .map((t) => t.replace(/^["']|["']$/g, ""))
    .filter(Boolean);
}

const isDir = (p: string) => existsSync(p) && statSync(p).isDirectory();

/** Đọc mọi lệnh mà một thư mục cấu hình (.claude hoặc ~/.claude) tạo ra, kèm các file "bẫy" không tạo lệnh. */
export function scanConfigDir(configDir: string): { entries: SkillEntry[]; flatInSkills: string[] } {
  const entries: SkillEntry[] = [];
  const flatInSkills: string[] = [];
  const skillsDir = join(configDir, "skills");
  if (isDir(skillsDir)) {
    for (const name of readdirSync(skillsDir).sort()) {
      const p = join(skillsDir, name);
      if (isDir(p)) {
        const f = join(p, "SKILL.md");
        if (!existsSync(f)) continue; // thư mục không có SKILL.md: không phải skill
        const { frontmatter, body } = parseFrontmatter(readFileSync(f, "utf8"));
        entries.push({ name: frontmatter.name || name, kind: "skill", file: f, frontmatter, body });
      } else if (name.endsWith(".md")) {
        flatInSkills.push(p);
      }
    }
  }
  const commandsDir = join(configDir, "commands");
  if (isDir(commandsDir)) {
    for (const name of readdirSync(commandsDir).sort()) {
      if (!name.endsWith(".md")) continue;
      const f = join(commandsDir, name);
      const { frontmatter, body } = parseFrontmatter(readFileSync(f, "utf8"));
      entries.push({ name: basename(name, ".md"), kind: "command", file: f, frontmatter, body });
    }
  }
  return { entries, flatInSkills };
}

/** Gộp theo tên: skill thắng command cùng tên (cùng một nguồn). */
export function effectiveCommands(entries: SkillEntry[]): Map<string, SkillEntry> {
  const out = new Map<string, SkillEntry>();
  for (const e of entries) {
    const cur = out.get(e.name);
    if (!cur || (cur.kind === "command" && e.kind === "skill")) out.set(e.name, e);
  }
  return out;
}
lint_skills.ts
// Bài 3.2 – lint thư mục .claude: bắt các lỗi đặt skill/command hay gặp. Chạy thật, không gọi model.
// Dùng: node --experimental-strip-types lint_skills.ts <repo> [<repo> …]
//
// Về allowed-tools (chỗ đề thi và thực tế khác nhau):
//   - Đề thi (exam guide v1.0): allowed-tools GIỚI HẠN tool skill được dùng.
//   - Claude Code hiện nay: allowed-tools chỉ PRE-APPROVE (dùng không hỏi quyền) trong lượt gọi skill;
//     mọi tool khác vẫn gọi được. Giới hạn thật: disallowed-tools hoặc luật deny trong permissions.
import { existsSync, readFileSync } from "node:fs";
import { join, relative } from "node:path";
import { effectiveCommands, scanConfigDir, toolList } from "./skill_files.ts";

export interface Finding {
  level: "lỗi" | "cảnh báo" | "ghi chú";
  file: string;
  message: string;
}

const WRITE_TOOLS = ["Write", "Edit", "Bash", "NotebookEdit"];
// Dấu hiệu skill "khám phá / nói nhiều": nên chạy trong subagent (context: fork).
const EXPLORE_RE = /\b(grep|glob|read)\b|khám phá|phân tích|brainstorm|explore|analy[sz]e|toàn bộ codebase/i;
// Dấu hiệu skill chỉ đọc.
const READ_ONLY_RE = /chỉ đọc|read-only|không sửa|không ghi/i;

export function lintRepo(repo: string): Finding[] {
  const out: Finding[] = [];
  const rel = (p: string) => relative(repo, p) || ".";
  const { entries, flatInSkills } = scanConfigDir(join(repo, ".claude"));

  for (const f of flatInSkills) {
    out.push({ level: "lỗi", file: rel(f), message: "File .md phẳng trong .claude/skills/ KHÔNG tạo lệnh. Đổi thành thư mục <tên>/SKILL.md, hoặc chuyển sang .claude/commands/." });
  }

  const byName = new Map<string, string[]>();
  for (const e of entries) byName.set(e.name, [...(byName.get(e.name) ?? []), e.kind]);
  for (const [name, kinds] of byName) {
    if (kinds.includes("skill") && kinds.includes("command")) {
      out.push({ level: "cảnh báo", file: `/${name}`, message: "Skill và command trùng tên: skill thắng, file trong .claude/commands/ bị che." });
    }
  }

  for (const e of entries) {
    const fm = e.frontmatter;
    const f = rel(e.file);
    if (!fm.description) {
      out.push({ level: "cảnh báo", file: f, message: "Thiếu description: Claude không tự chọn được skill theo yêu cầu (chỉ chạy khi gõ /lệnh); Claude Code lấy đoạn đầu thân bài thay thế." });
    }
    const exploratory = EXPLORE_RE.test(e.body) || EXPLORE_RE.test(fm.description ?? "");
    if (e.kind === "skill" && exploratory && fm.context !== "fork") {
      out.push({ level: "cảnh báo", file: f, message: "Skill khám phá/nhiều output nhưng thiếu `context: fork`: output dài sẽ đổ vào hội thoại chính." });
    }
    const allowed = toolList(fm["allowed-tools"]);
    const writes = allowed.filter((t) => WRITE_TOOLS.some((w) => t === w || t.startsWith(`${w}(`)));
    if (writes.length && (READ_ONLY_RE.test(e.body) || exploratory)) {
      out.push({ level: "cảnh báo", file: f, message: `Skill đọc/khám phá nhưng allowed-tools có ${writes.join(", ")}: chỉ nên Read Grep Glob.` });
    }
    if (allowed.length && !fm["disallowed-tools"]) {
      out.push({ level: "ghi chú", file: f, message: `allowed-tools (${allowed.join(" ")}) chỉ pre-approve trong Claude Code hiện nay, KHÔNG giới hạn. Muốn chặn thật: disallowed-tools hoặc deny trong permissions. (Đề thi coi allowed-tools là giới hạn.)` });
    }
  }

  // Quy trình nhiều bước nằm trong CLAUDE.md: nên là skill/command (nạp khi cần, không nạp mọi phiên).
  for (const md of [join(repo, "CLAUDE.md"), join(repo, ".claude", "CLAUDE.md")]) {
    if (!existsSync(md)) continue;
    const text = readFileSync(md, "utf8");
    const steps = text.split("\n").filter((l) => /^\s*\d+\.\s/.test(l)).length;
    if (steps >= 5) {
      out.push({ level: "cảnh báo", file: rel(md), message: `CLAUDE.md có quy trình ${steps} bước đánh số: quy trình theo việc nên chuyển thành skill/command (CLAUDE.md nạp mọi phiên).` });
    }
  }
  return out;
}

export function summarize(repo: string): string[] {
  const { entries } = scanConfigDir(join(repo, ".claude"));
  return [...effectiveCommands(entries).values()].map((e) => `/${e.name} (${e.kind}${e.frontmatter.context === "fork" ? ", context: fork" : ""})`);
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const repos = process.argv.slice(2);
  if (!repos.length) {
    console.error("Dùng: lint_skills.ts <repo> [<repo> …]");
    process.exit(2);
  }
  let errors = 0;
  for (const repo of repos) {
    console.log(`== ${repo}`);
    console.log(`Lệnh tạo ra: ${summarize(repo).join(", ") || "(không có)"}`);
    for (const f of lintRepo(repo)) {
      if (f.level === "lỗi") errors++;
      console.log(`  [${f.level}] ${f.file}: ${f.message}`);
    }
  }
  process.exitCode = errors ? 1 : 0;
}

// Bài 3.2 – mô hình tĩnh "phiên nào thấy lệnh nào" (bước 5: ranh giới chia sẻ). Không gọi model.
// Nguồn lệnh của một phiên = project (.claude/ trong repo, đi theo git) + user (~/.claude/, chỉ máy mình).
// Trùng tên giữa các nguồn: personal thắng project (docs: "Enterprise over personal, and personal over project").
// Dùng: node --experimental-strip-types expected_commands.ts [repo] [personal-skills-dir]
import { cpSync, mkdtempSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { effectiveCommands, scanConfigDir, type SkillEntry } from "./skill_files.ts";

export interface Visible {
  name: string;
  source: "project" | "user";
  kind: SkillEntry["kind"];
  fork: boolean;
}

/** userConfigDir: thư mục kiểu ~/.claude của máy đó (có skills/, commands/); undefined = máy người mới clone. */
export function visibleCommands(repo: string, userConfigDir?: string): Visible[] {
  const proj = effectiveCommands(scanConfigDir(join(repo, ".claude")).entries);
  const user = userConfigDir ? effectiveCommands(scanConfigDir(userConfigDir).entries) : new Map<string, SkillEntry>();
  const merged = new Map<string, Visible>();
  for (const [n, e] of proj) merged.set(n, { name: n, source: "project", kind: e.kind, fork: e.frontmatter.context === "fork" });
  for (const [n, e] of user) merged.set(n, { name: n, source: "user", kind: e.kind, fork: e.frontmatter.context === "fork" });
  return [...merged.values()].sort((a, b) => a.name.localeCompare(b.name));
}

/** Bảng so sánh cho các lệnh của bài tập. */
export function table(repo: string, personalConfigDir: string): { name: string; newcomer: boolean; me: boolean }[] {
  const names = ["review", "analyse-feature", "lint", "brainstorm"];
  const fresh = new Set(visibleCommands(repo).map((v) => v.name));
  const mine = new Set(visibleCommands(repo, personalConfigDir).map((v) => v.name));
  return names.map((name) => ({ name, newcomer: fresh.has(name), me: mine.has(name) }));
}

/** Dựng một thư mục giả lập ~/.claude chỉ chứa skills/brainstorm (copy từ personal/). Không đụng ~/.claude thật. */
export function fakeUserConfig(personalDir: string): string {
  const dir = mkdtempSync(join(tmpdir(), "cca32-home-"));
  cpSync(join(personalDir, "brainstorm"), join(dir, "skills", "brainstorm"), { recursive: true });
  return dir;
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const here = import.meta.dirname;
  const repo = process.argv[2] ?? join(here, "demo-repo");

  }

}

# Bài 3.2 – bước 2: cài skill CÁ NHÂN /brainstorm vào ~/.claude/skills/brainstorm (user-level, không đi theo git).

ask() { # ask <thư mục clone> <tên output> <prompt> [cờ thêm…]

// Bài 3.2 – đọc stream-json của run_cli.sh, in bảng kết quả. Không gọi model.
// Dùng: node --experimental-strip-types report_cli.ts <results_cli>
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { readStream, resultEvent, type StreamEvent } from "../lib/cli_stream.ts";

export const DEMO_NAMES = ["review", "analyse-feature", "lint", "brainstorm"];

const text = (c: unknown): string =>
  typeof c === "string" ? c : Array.isArray(c) ? c.map((b: any) => (typeof b === "string" ? b : (b?.text ?? JSON.stringify(b)))).join("") : JSON.stringify(c ?? "");

/** Tên lệnh/skill thấy trong system:init (bỏ tiền tố plugin như "superpowers:"; chỉ giữ 4 tên của bài). */
export function listedNames(events: StreamEvent[]): { skills: string[]; slash: string[] } {
  const init = events.find((e) => e.type === "system" && e.subtype === "init");
  const pick = (arr: unknown) =>
    (Array.isArray(arr) ? arr : []).map((x) => String(typeof x === "string" ? x : ((x as any)?.name ?? ""))).filter((n) => DEMO_NAMES.includes(n));
  return { skills: pick(init?.skills), slash: pick(init?.slash_commands) };
}

export interface Isolation {
  mainToolCalls: number; // tool_use do hội thoại chính gọi (parent_tool_use_id = null)
  mainToolChars: number; // ký tự tool_use + tool_result nằm trong hội thoại chính
  forkToolCalls: number; // tool_use trong subagent / forked skill
  forkToolChars: number;
  forkedCommand: boolean; // có message mang parent "forked-command-…"
  skillToolCalled: boolean; // Claude gọi tool Skill (tự chọn skill nhờ description)
  resultChars: number; // độ dài câu trả lời cuối
  costUsd?: number;
}

export function isolation(events: StreamEvent[]): Isolation {
  const r: Isolation = { mainToolCalls: 0, mainToolChars: 0, forkToolCalls: 0, forkToolChars: 0, forkedCommand: false, skillToolCalled: false, resultChars: 0 };
  for (const e of events) {
    if (e.type !== "assistant" && e.type !== "user") continue;
    const parent = e.parent_tool_use_id ?? null;
    if (typeof parent === "string" && parent.startsWith("forked-command-")) r.forkedCommand = true;
    const blocks = Array.isArray(e.message?.content) ? e.message!.content : [];
    for (const b of blocks) {
      let chars = 0;
      if (b.type === "tool_use") {
        chars = JSON.stringify(b.input ?? {}).length;
        if (parent === null && b.name === "Skill") r.skillToolCalled = true;
        if (parent === null) r.mainToolCalls++;
        else r.forkToolCalls++;
      } else if (b.type === "tool_result") {
        chars = text(b.content).length;
      } else continue;
      if (parent === null) r.mainToolChars += chars;
      else r.forkToolChars += chars;
    }
  }
  const res = resultEvent(events);
  r.resultChars = String(res?.result ?? "").length;
  r.costUsd = typeof res?.total_cost_usd === "number" ? res.total_cost_usd : undefined;
  return r;
}

export function report(dir: string): string[] {
  const out: string[] = [];
  const load = (n: string) => readStream(join(dir, `${n}.jsonl`));
  const status = existsSync(join(dir, "personal_status.txt")) ? readFileSync(join(dir, "personal_status.txt"), "utf8").trim() : "(không rõ)";
  const personal = status.startsWith("ĐÃ CÀI");

  const list = load("list");
  if (list.length) {
    const { skills, slash } = listedNames(list);
    const seen = new Set([...skills, ...slash]);
    out.push("== Bước 1, 5: lệnh thấy được trong system:init (clone)");
    out.push(`Skill cá nhân /brainstorm: ${status}`);
    const want: Record<string, boolean> = { review: true, "analyse-feature": true, lint: false, brainstorm: personal };
    for (const n of DEMO_NAMES) {
      const ok = seen.has(n) === want[n];
      out.push(`  ${ok ? "OK  " : "LỆCH"} /${n.padEnd(16)} thấy=${seen.has(n) ? "có" : "không"}  mong đợi=${want[n] ? "có" : "không"}`);
    }
  }

  const rows = ["fork", "nofork", "auto"].map((n) => [n, load(n)] as const).filter(([, ev]) => ev.length);
  if (rows.length) {
    out.push("", "== Bước 6: output của skill có đổ vào hội thoại chính không");
    out.push("phiên    tool chính  ký tự chính  tool fork  ký tự fork  forked-command  gọi Skill  câu trả lời  USD");
    for (const [n, ev] of rows) {
      const i = isolation(ev);
      out.push(
        `${n.padEnd(8)} ${String(i.mainToolCalls).padStart(10)}  ${String(i.mainToolChars).padStart(11)}  ${String(i.forkToolCalls).padStart(9)}  ${String(i.forkToolChars).padStart(10)}  ${(i.forkedCommand ? "có" : "không").padStart(14)}  ${(i.skillToolCalled ? "có" : "không").padStart(9)}  ${String(i.resultChars).padStart(11)}  ${i.costUsd?.toFixed(4) ?? "?"}`,
      );
    }
    const f = rows.find(([n]) => n === "fork");
    const nf = rows.find(([n]) => n === "nofork");
    if (f && nf) {
      const a = isolation(f[1]);
      const b = isolation(nf[1]);
      out.push("", `Kết luận: nội dung tool trong hội thoại chính: fork ${a.mainToolChars} ký tự, nofork ${b.mainToolChars} ký tự.`);
      out.push(a.mainToolChars < b.mainToolChars ? "→ context: fork giữ output khám phá ngoài hội thoại chính." : "→ KHÔNG thấy khác biệt như mong đợi: đọc lại stream-json.");
    }
  }
  return out;
}

  • Skill là quy trình nạp khi cần, CLAUDE.md là quy ước luôn nạp. Không nhét quy trình nhiều bước vào CLAUDE.md, không dùng skill cho quy ước phải áp dụng mọi lần sửa.
  • .claude/ = project, đi theo git; ~/.claude/ = cá nhân. Mẫu này lặp lại cho CLAUDE.md, commands, skills, rules.
  • Bẫy đề thi:
    1. File phẳng trong .claude/skills/ không tạo lệnh (phải là <tên>/SKILL.md; file phẳng chỉ chạy trong .claude/commands/).
    2. Lệnh của team đặt ở ~/.claude/: người khác không có.
    3. Dùng skill cho quy ước luôn áp dụng: phải là CLAUDE.md hoặc .claude/rules/.
    4. Output khám phá dài làm loãng hội thoại chính: thêm context: fork.
    5. Quy trình review/phân tích viết trong CLAUDE.md: chuyển thành skill.
  • Câu luyện tập: /review cho cả team, /brainstorm cá nhân, output dài. Đáp án C: /review ở .claude/commands/, /brainstorm ở ~/.claude/skills/brainstorm/SKILL.md với context: fork. A: thư mục cá nhân không chia sẻ. B: skill cá nhân thành của chung. D: quy trình không đặt trong CLAUDE.md, và allowed-tools không cô lập output.
