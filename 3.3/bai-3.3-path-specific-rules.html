1. Mục tiêu

Đặt quy ước cho một loại file nằm rải rác nhiều thư mục (test co-located, file API, Terraform) vào .claude/rules/ với frontmatter paths, rồi đo được rule nào thật sự được nạp khi Claude chạm vào từng loại file và tiết kiệm bao nhiêu token so với gom hết vào root CLAUDE.md. Cách đo giống bài 3.1: mỗi rule chứa một mã CANARY riêng; Claude chỉ in được mã của rule đã vào context.

Rules và skills đều có paths, khác nhau thế nào?

  • Rule: quy ước nền, nằm trong context và định hướng mọi lần sửa file khớp. Muốn quy ước tự áp dụng theo loại file → rule.
  • Skill: quy trình gọi khi cần; paths chỉ giúp Claude tự gợi ý dùng skill. Đặt quy ước test vào skill thì phụ thuộc vào việc có ai gọi nó (đáp án D của câu luyện tập).

7. Đã xác minh từ tài liệu

Nguồn: How Claude remembers your project, mục Organize rules with .claude/rules/ (đọc ngày 15/10/2026).

  • paths nhận YAML list hoặc chuỗi phân tách dấu phẩy; hỗ trợ brace {ts,tsx} (ngân sách 1.000 pattern sau khi mở, vượt thì pattern được dùng nguyên văn và không khớp gì).
  • Rule có paths nạp khi Claude dùng Read, Write hoặc Edit trên file khớp, hoặc xem file bằng lệnh Bash được tính là đọc (cat, head một file).
  • Rule không có paths nạp lúc khởi động, cùng mức với .claude/CLAUDE.md.
  • Frontmatter không parse được → bị bỏ, rule nạp như không có paths (tức mọi phiên). paths là field duy nhất được đọc.
  • Sau /compact: root CLAUDE.md được đọc lại ngay; rule có paths chỉ nạp lại khi Claude chạm lại file khớp.
  • Bỏ project khỏi --setting-sources thì rule của project bị bỏ.
Chưa chắc. Khi rule được nạp giữa chừng (sau một lần Read), nó đi vào context theo dạng nào (nhắc kèm tool_result hay khối riêng) và có hiện trong stream-json không. Bài không dựa vào điều đó: Claude tự in CANARY sau khi đọc.

Chạy bằng node --experimental-strip-types (Node ≥ 22.6), không cần cài gói.

match_rules.ts — matcher glob, frontmatter, bảng file → rule, token
// Bài 3.3 – mô hình tĩnh: sửa/đọc file nào thì rule nào trong .claude/rules/ được nạp, và tốn bao nhiêu token.
//
// Theo tài liệu memory của Claude Code (code.claude.com/docs/en/memory, mục "Path-specific rules"):
//   - rule KHÔNG có `paths` → nạp lúc khởi động, mọi phiên;
//   - rule có `paths` → nạp khi Claude dùng Read/Write/Edit (hoặc `cat`/`head` một file) trên file khớp glob;
//   - `paths` nhận YAML list hoặc chuỗi phân tách bằng dấu phẩy; hỗ trợ brace `{ts,tsx}`;
//   - frontmatter không parse được → bỏ frontmatter, rule nạp như KHÔNG có `paths` (tức là mọi phiên);
//   - `paths` là field DUY NHẤT được đọc, field khác bị bỏ qua.
// Glob tính từ gốc project (vd `*.md` chỉ khớp file ở gốc).
//
// Dùng: node --experimental-strip-types match_rules.ts [demo-repo] [variant-root]
import { existsSync, readdirSync, readFileSync, statSync } from "node:fs";
import { join, relative, sep } from "node:path";

export const CANARY_RE = /CANARY-[A-Z0-9-]+/g;

// ---------- glob ----------

/** Mở brace `{a,b}` thành nhiều pattern (lồng nhau được). */
export function expandBraces(pattern: string): string[] {
  const open = pattern.indexOf("{");
  if (open < 0) return [pattern];
  let depth = 0;
  for (let i = open; i < pattern.length; i++) {
    if (pattern[i] === "{") depth++;
    else if (pattern[i] === "}" && --depth === 0) {
      const inner = pattern.slice(open + 1, i);
      const parts: string[] = [];
      let d = 0;
      let start = 0;
      for (let j = 0; j < inner.length; j++) {
        if (inner[j] === "{") d++;
        else if (inner[j] === "}") d--;
        else if (inner[j] === "," && d === 0) {
          parts.push(inner.slice(start, j));
          start = j + 1;
        }
      }
      parts.push(inner.slice(start));
      const head = pattern.slice(0, open);
      const tail = pattern.slice(i + 1);
      return parts.flatMap((p) => expandBraces(head + p + tail));
    }
  }
  return [pattern]; // brace không đóng: giữ nguyên, khớp chữ
}

/** Chuyển một glob (đã mở brace) thành RegExp. Hỗ trợ `**`, `*`, `?`, `[abc]`. */
export function globToRegExp(glob: string): RegExp {
  let re = "";
  for (let i = 0; i < glob.length; i++) {
    const c = glob[i];
    if (c === "*") {
      if (glob[i + 1] === "*") {
        const atStart = i === 0 || glob[i - 1] === "/";
        const atEnd = i + 2 === glob.length || glob[i + 2] === "/";
        if (atStart && atEnd) {
          // `**/` = 0 hoặc nhiều thư mục; `**` ở cuối = mọi thứ còn lại
          if (glob[i + 2] === "/") {
            re += "(?:[^/]+/)*";
            i += 2;
          } else {
            re += ".*";
            i += 1;
          }
          continue;
        }
        re += "[^/]*";
        i += 1;
        continue;
      }
      re += "[^/]*";
    } else if (c === "?") re += "[^/]";
    else if (c === "[") {
      const close = glob.indexOf("]", i + 1);
      if (close < 0) return /(?!)/; // `[` không đóng: pattern không hợp lệ, không khớp gì (như tài liệu)
      re += "[" + glob.slice(i + 1, close).replace(/\\/g, "\\\\") + "]";
      i = close;
    } else if (c === "\\" && i + 1 < glob.length) {
      re += "\\" + glob[++i];
    } else re += c.replace(/[.+^${}()|]/g, "\\$&");
  }
  return new RegExp(`^${re}$`);
}

export function matchGlob(file: string, pattern: string): boolean {
  const f = file.split(sep).join("/");
  return expandBraces(pattern).some((p) => globToRegExp(p).test(f));
}

// ---------- frontmatter ----------

export interface Frontmatter {
  paths: string[] | null; // null = không có paths → nạp mọi phiên
  body: string;
  error?: string; // frontmatter hỏng → bị bỏ, rule nạp mọi phiên
  ignoredFields: string[];
}

const unquote = (s: string) => s.trim().replace(/^["']|["']$/g, "");

export function parseFrontmatter(text: string): Frontmatter {
  if (!text.startsWith("---\n")) return { paths: null, body: text, ignoredFields: [] };
  const end = text.indexOf("\n---", 4);
  if (end < 0) return { paths: null, body: text, error: "thiếu dòng `---` đóng frontmatter", ignoredFields: [] };
  const yaml = text.slice(4, end).split("\n");
  const body = text.slice(text.indexOf("\n", end + 1) + 1);
  let paths: string[] | null = null;
  const ignored: string[] = [];
  for (let i = 0; i < yaml.length; i++) {
    const line = yaml[i];
    if (!line.trim() || line.trim().startsWith("#")) continue;
    const m = line.match(/^([A-Za-z_][\w-]*):\s*(.*)$/);
    if (!m) return { paths: null, body, error: `dòng YAML không hợp lệ: "${line}"`, ignoredFields: [] };
    const [, key, rest] = m;
    if (key !== "paths") {
      ignored.push(key);
      continue;
    }
    if (rest.startsWith("[")) {
      if (!rest.endsWith("]")) return { paths: null, body, error: "mảng `paths: [...]` không đóng", ignoredFields: [] };
      paths = rest.slice(1, -1).split(",").map(unquote).filter(Boolean);
    } else if (rest.trim()) {
      paths = rest.split(",").map(unquote).filter(Boolean); // chuỗi phân tách bằng dấu phẩy
    } else {
      paths = [];
      while (i + 1 < yaml.length && /^\s+-\s/.test(yaml[i + 1])) paths.push(unquote(yaml[++i].replace(/^\s+-\s/, "")));
      if (!paths.length) return { paths: null, body, error: "`paths:` không có giá trị", ignoredFields: [] };
    }
  }
  return { paths, body, ignoredFields: ignored };
}

// ---------- repo ----------

export interface Rule {
  file: string; // đường dẫn tương đối từ gốc repo
  fm: Frontmatter;
  chars: number; // độ dài phần được đưa vào context (đã bỏ frontmatter)
  canaries: string[];
}

export function listFiles(root: string, dir = root): string[] {
  const out: string[] = [];
  for (const name of readdirSync(dir).sort()) {
    if (name === ".git" || name === "node_modules" || name === ".claude") continue;
    const p = join(dir, name);
    if (statSync(p).isDirectory()) out.push(...listFiles(root, p));
    else out.push(relative(root, p).split(sep).join("/"));
  }
  return out;
}

export function loadRules(repo: string): Rule[] {
  const dir = join(repo, ".claude", "rules");
  if (!existsSync(dir)) return [];
  return readdirSync(dir)
    .filter((f) => f.endsWith(".md"))
    .sort()
    .map((f) => {
      const fm = parseFrontmatter(readFileSync(join(dir, f), "utf8"));
      return { file: `.claude/rules/${f}`, fm, chars: fm.body.length, canaries: fm.body.match(CANARY_RE) ?? [] };
    });
}

export interface Loaded {
  source: string;
  reason: "luôn nạp" | "khớp paths";
  chars: number;
  canaries: string[];
}

/** Những gì nằm trong context khi Claude đã Read/Edit các file `touched` (đường dẫn tương đối). */
export function loadedFor(repo: string, touched: string[]): Loaded[] {
  const out: Loaded[] = [];
  const claudeMd = join(repo, "CLAUDE.md");
  if (existsSync(claudeMd)) {
    const t = readFileSync(claudeMd, "utf8");
    out.push({ source: "CLAUDE.md", reason: "luôn nạp", chars: t.length, canaries: t.match(CANARY_RE) ?? [] });
  }
  for (const r of loadRules(repo)) {
    if (r.fm.paths === null) out.push({ source: r.file, reason: "luôn nạp", chars: r.chars, canaries: r.canaries });
    else if (touched.some((f) => r.fm.paths!.some((p) => matchGlob(f, p))))
      out.push({ source: r.file, reason: "khớp paths", chars: r.chars, canaries: r.canaries });
  }
  return out;
}

/** Mọi mã CANARY có trong context khi đã chạm các file `touched`. */
export const canariesFor = (repo: string, touched: string[]): string[] =>
  [...new Set(loadedFor(repo, touched).flatMap((l) => l.canaries))].sort();

/** Ước lượng token thô: ~4 ký tự / token (tiếng Việt có dấu thường tốn hơn; chỉ dùng để so tương đối). */
export const tokens = (chars: number) => Math.round(chars / 4);

export function ruleTable(repo: string): { file: string; rules: string[] }[] {
  return listFiles(repo).map((f) => ({
    file: f,
    rules: loadRules(repo)
      .filter((r) => r.fm.paths !== null && r.fm.paths.some((p) => matchGlob(f, p)))
      .map((r) => r.file.replace(".claude/rules/", "")),
  }));
}

export const SAMPLE_FILES = [
  { kind: "test", file: "src/auth/auth.test.ts" },
  { kind: "api", file: "src/api/customers.ts" },
  { kind: "terraform", file: "terraform/main.tf" },
  { kind: "utils", file: "src/utils/format.ts" },
];

export function tokenTable(repo: string, variantRoot: string) {
  return SAMPLE_FILES.map(({ kind, file }) => {
    const rules = loadedFor(repo, [file]).reduce((s, l) => s + l.chars, 0);
    const root = loadedFor(variantRoot, [file]).reduce((s, l) => s + l.chars, 0);
    return { kind, file, rulesTokens: tokens(rules), rootTokens: tokens(root), saved: 1 - rules / root };
  });
}

lint_rules.ts — bắt anti-pattern
// Bài 3.3 – lint cấu hình quy ước: bắt các anti-pattern của bài path-specific rules.
//
//   WARN  frontmatter hỏng → tài liệu: bị bỏ qua, rule nạp MỌI phiên (mất tác dụng giới hạn theo path)
//   WARN  `paths` không khớp file nào (glob gõ sai, vd *.tset.ts) → rule không bao giờ được nạp
//   WARN  nhiều CLAUDE.md thư mục có nội dung gần giống nhau → nên gộp thành 1 rule + glob
//   WARN  pattern có brace vượt ngân sách 1.000 pattern sau khi mở → Claude Code dùng nguyên văn, không khớp gì
//   INFO  root CLAUDE.md có quy ước theo LOẠI FILE (test, terraform, controller…) → nên chuyển sang rule có paths
//   INFO  rule trông như QUY TRÌNH nhiều bước → nên là skill (bài 3.2), không phải quy ước nền
//   INFO  field frontmatter khác `paths` → bị bỏ qua (paths là field duy nhất Claude Code đọc)
//
// Dùng: node --experimental-strip-types lint_rules.ts [repo]
import { existsSync, readFileSync } from "node:fs";
import { dirname, join } from "node:path";
import { expandBraces, listFiles, loadRules, matchGlob } from "./match_rules.ts";

export interface Finding {
  level: "WARN" | "INFO";
  file: string;
  message: string;
}

const FILE_TYPE_HINT = /\.test\.|\.spec\.|\*\.tf\b|terraform|\.controller\.|file test|test file|migration file|quy ước (test|api)|hạ tầng/i;
const STEP_LINE = /^\s*(\d+[.)]|bước\s*\d+|step\s*\d+)/i;

function normalize(s: string): string[] {
  return s
    .split("\n")
    .map((l) => l.trim().toLowerCase())
    .filter((l) => l && !l.startsWith("#") && !/canary-/i.test(l));
}

function similarity(a: string[], b: string[]): number {
  const sa = new Set(a);
  const sb = new Set(b);
  const inter = [...sa].filter((x) => sb.has(x)).length;
  return inter / Math.max(1, Math.min(sa.size, sb.size));
}

export function lint(repo: string): Finding[] {
  const out: Finding[] = [];
  const files = listFiles(repo);
  const codeFiles = files.filter((f) => !f.endsWith("CLAUDE.md"));

  for (const r of loadRules(repo)) {
    if (r.fm.error)
      out.push({ level: "WARN", file: r.file, message: `frontmatter hỏng (${r.fm.error}) → Claude Code bỏ frontmatter, rule nạp MỌI phiên` });
    for (const k of r.fm.ignoredFields)
      out.push({ level: "INFO", file: r.file, message: `field "${k}" bị bỏ qua: rule chỉ đọc \`paths\`` });
    if (r.fm.paths) {
      const expanded = r.fm.paths.reduce((s, p) => s + (p.includes("{") ? expandBraces(p).length : 0), 0);
      if (expanded > 1000)
        out.push({ level: "WARN", file: r.file, message: `brace mở ra ${expanded} pattern (> 1.000): pattern vượt ngân sách được dùng nguyên văn và không khớp gì` });
      for (const p of r.fm.paths)
        if (!codeFiles.some((f) => matchGlob(f, p)))
          out.push({ level: "WARN", file: r.file, message: `pattern "${p}" không khớp file nào trong repo (gõ sai glob?)` });
    }
    const steps = r.fm.body.split("\n").filter((l) => STEP_LINE.test(l)).length;
    if (steps >= 4)
      out.push({ level: "INFO", file: r.file, message: `${steps} dòng dạng "bước 1, 2, 3…": giống quy trình → nên là skill (gọi khi cần), không phải quy ước nền` });
  }

  const root = join(repo, "CLAUDE.md");
  if (existsSync(root)) {
    const hits = readFileSync(root, "utf8")
      .split("\n")
      .filter((l) => FILE_TYPE_HINT.test(l) && !l.includes(".claude/rules"));
    if (hits.length >= 2)
      out.push({
        level: "INFO",
        file: "CLAUDE.md",

      });
  }

  const nested = files.filter((f) => f.endsWith("/CLAUDE.md"));
  const bodies = nested.map((f) => ({ f, lines: normalize(readFileSync(join(repo, f), "utf8")) }));
  const groups: string[][] = [];
  const used = new Set<string>();
  for (const a of bodies) {
    if (used.has(a.f)) continue;
    const g = [a.f, ...bodies.filter((b) => b.f !== a.f && !used.has(b.f) && similarity(a.lines, b.lines) >= 0.8).map((b) => b.f)];
    if (g.length >= 2) {
      g.forEach((f) => used.add(f));
      groups.push(g);
    }
  }
  for (const g of groups)
    out.push({
      level: "WARN",
      file: g.map((f) => dirname(f)).join(", "),
      message: `${g.length} CLAUDE.md thư mục gần như giống nhau → bản sao sẽ lệch nhau theo thời gian; gộp thành 1 rule trong .claude/rules/ với glob`,
    });
  return out;
}

import { cpSync, existsSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { loadRules } from "./match_rules.ts";

export function buildVariantClaudeMd(repo: string): string {
  const base = readFileSync(join(repo, "CLAUDE.md"), "utf8").trimEnd();
  const sections = loadRules(repo).map(
    (r) => `<!-- gộp từ ${r.file}${r.fm.paths ? ` (paths: ${r.fm.paths.join(", ")})` : ""} -->\n${r.fm.body.trim()}`,
  );
  return [
    "<!-- FILE SINH TỰ ĐỘNG bởi make_variant.ts từ demo-repo. Đừng sửa tay. -->",
    base,
    ...sections,
  ].join("\n\n") + "\n";
}

export function makeVariant(repo: string, out: string): void {
  if (existsSync(out)) rmSync(out, { recursive: true });
  cpSync(repo, out, { recursive: true, filter: (src) => !src.includes(`${join(repo, ".claude")}`) });
  writeFileSync(join(out, "CLAUDE.md"), buildVariantClaudeMd(repo));
}

report_cli.ts — so CANARY và token
// Bài 3.3 – so CANARY mà Claude in ra (stream-json của run_cli.sh) với mô hình match_rules.ts,
// và so input token thật giữa hai biến thể (rules theo path vs gom vào root CLAUDE.md).
// Dùng: node --experimental-strip-types report_cli.ts <results_cli> <.tmp>
import { existsSync } from "node:fs";
import { join } from "node:path";
import { readStream, resultEvent, toolUses } from "../lib/cli_stream.ts";
import { CANARY_RE, canariesFor, SAMPLE_FILES } from "./match_rules.ts";

export const CASES = [{ kind: "none", file: "" }, ...SAMPLE_FILES];

export interface Row {
  variant: string;
  kind: string;
  file: string;
  expected: string[];
  seen: string[];
  missing: string[];
  extra: string[];
  reads: string[];
  inputTokens?: number;
  costUsd?: number;
  ok: boolean;
}

/** Tổng token đầu vào của lệnh (kể cả phần ghi/đọc cache), lấy từ result.usage nếu có. */
function inputTokensOf(usage: any): number | undefined {
  if (!usage) return undefined;
  return (usage.input_tokens ?? 0) + (usage.cache_creation_input_tokens ?? 0) + (usage.cache_read_input_tokens ?? 0);
}

export function compare(resultsDir: string, tmpDir: string): Row[] {
  const rows: Row[] = [];
  for (const variant of ["rules", "root"]) {
    for (const c of CASES) {
      const path = join(resultsDir, variant, `${c.kind}.jsonl`);
      if (!existsSync(path)) continue;
      const events = readStream(path);
      const expected = canariesFor(join(tmpDir, variant), c.file ? [c.file] : []);
      const res = resultEvent(events);
      const text =
        (res?.result as string | undefined) ??
        events
          .filter((e) => e.type === "assistant" && Array.isArray(e.message?.content))
          .flatMap((e) => e.message!.content.filter((b: any) => b.type === "text").map((b: any) => b.text))
          .join("\n");
      const seen = [...new Set(text.match(CANARY_RE) ?? [])].sort();
      const reads = toolUses(events)
        .filter((t) => t.name === "Read")
        .map((t) => String(t.input?.file_path ?? "").replace(/^.*?\/(?=src\/|terraform\/|routes\/|infrastructure\/)/, ""));
      const missing = expected.filter((x) => !seen.includes(x));
      const extra = seen.filter((x) => !expected.includes(x));
      rows.push({
        variant,
        kind: c.kind,
        file: c.file,
        expected,
        seen,
        missing,
        extra,
        reads,
        inputTokens: inputTokensOf(res?.usage),
        costUsd: res?.total_cost_usd,
        ok: !missing.length && !extra.length,
      });
    }
  }
  return rows;
}

export function render(rows: Row[]): string {
  const out: string[] = [];
  out.push(`${"biến thể".padEnd(8)} ${"ca".padEnd(10)} ${"đã Read".padEnd(24)} ${"input tok".padStart(9)}  kết quả`);
  for (const r of rows) {
    const verdict = r.ok ? "OK" : `KHÁC  thiếu=[${r.missing.join(" ")}] dư=[${r.extra.join(" ")}]`;
    out.push(
      `${r.variant.padEnd(8)} ${r.kind.padEnd(10)} ${(r.reads.join(",") || "—").padEnd(24)} ${String(r.inputTokens ?? "?").padStart(9)}  ${verdict}`,
    );
    out.push(`${"".padEnd(20)}thấy: ${r.seen.join(" ") || "NONE"}`);
  }
  const by = (v: string, k: string) => rows.find((r) => r.variant === v && r.kind === k)?.inputTokens;
  out.push("\nChênh input token (root − rules) cùng một ca — phần quy ước KHÔNG liên quan bị nạp thừa ở biến thể root:");
  for (const k of CASES.map((c) => c.kind)) {
    const a = by("rules", k);
    const b = by("root", k);
    if (a !== undefined && b !== undefined) out.push(`  ${k.padEnd(10)} rules=${a}  root=${b}  chênh=${b - a}`);
  }
  const cost = rows.reduce((s, r) => s + (r.costUsd ?? 0), 0);
  out.push(`\n${rows.filter((r) => r.ok).length}/${rows.length} ca khớp mô hình · tổng chi phí ${cost.toFixed(4)} USD`);
  return out.join("\n");
}

    console.error("Dùng: report_cli.ts <results_cli> <.tmp>");
    process.exit(2);
  }
  console.log(render(compare(resultsDir, tmpDir)));
}

11. Tiêu chí hoàn thành

  • 3 rule có paths dạng glob, mỗi rule ≥ 3 quy ước (test 5, API 4, Terraform 4)
  • 1 rule test phủ file test co-located ở 7 thư mục, không cần CLAUDE.md nào trong các thư mục đó
  • Bảng file → rule chứng minh file test chỉ kéo testing.md, file API chỉ kéo api-conventions.md, file utils không kéo rule nào
  • So sánh token: tách rules ít hơn gom vào root ở mọi loại file (ước lượng); số thật chờ lần chạy Claude

12. Bài học rút ra

  • Loại file rải nhiều thư mục → rule + glob. Một file, một chỗ sửa; thêm thư mục test mới không cần làm gì.
  • Rule chỉ nạp khi chạm file khớp nên không tốn token khi làm việc khác, khác root CLAUDE.md nạp mọi phiên.
  • Frontmatter hỏng là lỗi im lặng: rule vẫn chạy nhưng nạp mọi phiên. Glob gõ sai cũng im lặng theo chiều ngược lại: rule không bao giờ nạp. Vì vậy mới cần lint.
  • Rule là quy ước nền, skill là quy trình gọi khi cần; cả hai có paths nhưng vai trò khác nhau.

3 bẫy đề

  1. Chọn CLAUDE.md thư mục cho quy ước trải 50+ thư mục → phải là rule + glob.
  2. Đặt quy ước theo loại file vào root CLAUDE.md → tốn token khi sửa file không liên quan.
  3. Nhầm skill với rule cho việc tự nạp quy ước → rule mới là cơ chế nền tự động.

Câu luyện tập

Test co-located ở 50+ thư mục, team muốn quy ước test giống nhau ở mọi nơi. Cách dễ bảo trì nhất?

  • A. Gom vào root CLAUDE.md — nạp cả khi làm việc khác, tốn token
  • B. Một file trong .claude/rules/ với paths: **/*.test.tsx, **/*.test.ts — đúng
  • C. CLAUDE.md ở mọi thư mục có test — 50+ bản sao, lệch nhau dần
  • D. Skill chứa quy ước test, dev gọi trước khi viết test — phụ thuộc người nhớ gọi, không tự động
